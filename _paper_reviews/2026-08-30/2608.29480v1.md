## 公理审查结果

### 一 对象公理
- **判定: ✅　分数: 9**
- **依据:** 论文将"temporal music grounding"形式化为明确定义的对象：给定音频与文本查询，模型须返回被查询音符/事件/音型对应的时间区间。对象被拆解为两个可操作的子对象——MGBench-3N（音符级，最多 3 个音符，102,900 条 QA，覆盖全部 88 个钢琴键，含 ABS/REL/ORD/PAT 四类查询族，15% 空答案比例）与 MGBench-2B（两小节结构化定位 + 短音乐理解，训练/验证/测试 9,007/1,128/1,124 条材料，定位 63,240 条 + 理解 82,204 条 QA，7 个概念组）。任务定义、查询模板示例（如"Locate the pair of notes separated by 7 semitone(s)"）、评估协议（IFR、IoU@0.5/0.7、MergedIoU、Onset/Offset MAE）均在正文中完整给出。对象边界清晰、可操作化程度高。
- **Wiki 证据:** 全文第 3 节（Benchmark Construction）与第 4 节（Evaluation Protocol）提供完整的任务与指标定义；Table 1 列出全部子集与 QA 数量。

### 二 识别公理
- **判定: ⚠️　分数: 6**
- **依据:** 定位侧的识别设计优秀：MIDI 渲染到音频（PianoTeq 9 Stage）给出精确到 onset/offset 的符号-音频对齐，真值无需人工标注即客观可验证；IFR 与正确性分离，避免把"格式失败"误判为"定位失败"——这一分离在数据中得到体现（Music Flamingo 的 MergedIoU 高达 0.8944 但 IoU@0.5 F1 仅 0.0342，说明它输出长区间而非精确定位，两类指标共同完成了诊断）。但理解侧的识别有明确缺陷：所有指令微调模型的 Global Accuracy 均为 1.0000（IFR 与语义正确性皆满分），LLM judge（Qwen2.5-7B-Instruct）对自家训练出的模型输出明显过宽，使得 Global Accuracy 在微调模型之间完全失去区分力，只能退而依赖逐概念准确率；且 7 个概念组样本量严重不均（harmonic pattern 仅 51 条，rhythm 229 条），"grounding 监督提升理解"的探索性结论建立在 51 条样本的 0.5686→0.8627 波动上，统计效力不足。
- **Wiki 证据:** Table 2 中 Music Flamingo 的 MergedIoU/F1 失配；Table 3 中三个微调模型 Global Acc 全为 1.0000；逐概念样本量 229/230/230/115/155/114/51。

### 三 独立性公理
- **判定: ⚠️　分数: 6**
- **依据:** 基准对模型的独立性总体成立：评估指标（区间 IoU、MAE）为模型无关的客观度量，被评对象覆盖三类方法（基于 MERT 特征的非 LLM 定位器 FiLM/XAttn、零样本音频-LLM Music Flamingo 与 Qwen2-Audio-7B-Instruct、两种 LoRA 微调骨干 LLaMA-3-8B 与 Qwen3.5-9B-Base），结论可跨模型比较。但存在两处独立性削弱：(1) "Ours"模型在训练集与测试集同分布的合成数据上评估（9,007 训练 vs 1,124 测试来自同一生成流程），"task-specific training yields substantial gains"的结论本质上是 in-domain 结论，对真实音乐分布的泛化未被检验；(2) 理解评估与跨度抽取均依赖 Qwen2.5-7B-Instruct 充当裁判/抽取器，评估仪器与被评对象（同为 Qwen 系或同源训练数据）之间缺乏隔离说明。
- **Wiki 证据:** 第 5.1 节三模型类型设定；Table 2/3 中 Ours 模型 3N 测试集 900 条、2B 测试集 1,124 条均来自同一合成管线。

### 四 压缩公理
- **判定: ⚠️　分数: 5**
- **依据:** 设计上高度压缩受控：2B 子集在生成时显式采样控制变量（拍号、速度、调式、主音音高、音区、音程倾向、小节和声、重复类型、和声模式类型），并用验证/过滤强制单声部、边界合法与标签一致，超过 10 s 的片段被剔除——变量空间被压缩到可归因的程度，这是基准设计的正确做法。但压缩过度导致现象覆盖面收窄：全部素材为单声部（monophonic）合成钢琴，而论文自己在引言中强调音乐定位目标"relational, repeated, or structurally defined"，恰恰在复调、多乐器、真实录音中最难；此外 QA 数量存在注水——3N 每条训练/验证材料采样 20 条查询（102,900 条 QA 实际仅来自 6,000 条材料），同一材料的多条查询高度相关，总规模指标夸大了数据多样性。
- **Wiki 证据:** 第 3.2/3.3 节控制变量与过滤流程；3N 的 4,200/900/900 材料划分对应 102,900 条 QA（每材料 20 条查询）；全文素材限定"PianoTeq 9 Stage 渲染的单声部钢琴"。

### 五 效用公理
- **判定: ⚠️　分数: 6**
- **依据:** 诊断价值已被数据证实：零样本音频-LLM 在 3N 上近乎全军覆没（Qwen2-Audio IoU@0.5 F1 = 0.0000，IFR 仅 0.0006；Music Flamingo F1 = 0.0342、IFR 0.0842），在 2B 上同样失败（两者 F1 ≤ 0.011），证明现有音频-LLM 的流利音乐回答建立在音频证据之外的先验上——这是对社区有明确警示价值的负结果。理解侧也暴露出两个 SOTA 模型在和弦与和声模式概念上得分为 0.0000。微调后 Qwen3.5-9B 在 2B 上达 IoU@0.5 F1 0.9221、MAE 9.34/13.28 ms，验证了"可学性"。但效用受限三点：(1) 数据/代码/模型仅承诺"will be released soon"，截至评审时点 GitHub 检索为 0 结果，社区尚无法直接使用；(2) 素材限于单声部合成钢琴，结论外推到真实音乐场景的效用有限；(3) grounding 监督与理解的关系结论自述为 exploratory 且跨骨干不一致（LLaMA-3-8B 加 grounding 无提升，Qwen3.5-9B U+1.0G 0.6868 vs U 0.6512），暂不构成可迁移的训练建议。
- **Wiki 证据:** Table 2/3 全部数字；GitHub API 检索 0 结果；论文引言与结论中"will be released soon"表述。

### 六 新颖性公理
- **判定: ✅　分数: 8**
- **依据:** OpenAlex 检索证实了空白点的真实性：视频时间定位领域成熟（TALL 2018 已被引 365），音频-LLM 细粒度时间定位在 2024–2026 出现并行工作（AudioTime 2024、SpotSound 2026、Auto-AEG 2026），但它们面向一般声音事件；针对音乐域、以音符/音程/和弦音区/重复/和声模式等关系型与结构型目标为查询、并具备精确符号-音频对齐的时间定位基准，经检索确认本文为首个（"MusicGroundingBench" 在 OpenAlex 仅命中本文自身）。任务形式化（音乐目标的 relational/structural 特性）与「定位监督是否反哺理解」的实验问题设计亦有新意。扣分点：时间定位的评估协议（IoU 阈值匹配、区间 F1）基本沿用视频时间定位的成熟做法，方法层面无新设计。
- **Wiki 证据:** OpenAlex 检索结果（见顶部事实锚点）；论文 Related Work 明确区分视觉/视频定位、一般音频定位与音乐定位三线工作。

### 七 可复现公理
- **判定: ⚠️　分数: 4**
- **依据:** 有利面：数据为算法生成（MIDI 程序化生成 + PianoTeq 渲染），原则上可确定性复现；划分数量、控制变量、指标定义、训练设置（LoRA、MERT 特征经两层 MLP 投影、固定训练步数、按验证损失选 checkpoint）在正文中有较完整描述。不利面：截至评审时点未发布任何代码、数据或模型——GitHub 检索 "MusicGroundingBench" 与相关关键词均为 0 结果，论文仅写 "will be released soon" 未附链接；MIDI 生成算法、控制变量采样分布、查询模板全集、LLM judge 的具体 prompt 均未在正文中给出，第三方在无发布物的情况下无法复现 102,900/145,444 条 QA；PianoTeq 9 Stage 为商业授权软件，渲染环节的复现门槛额外存在。Semantic Scholar 引用数据查询因 429 失败，独立复现/验证信号不足。
- **Wiki 证据:** GitHub API 检索 0 结果（见事实锚点）；论文引言"Datasets, code, and models will be released soon"；Semantic Scholar API 429 错误记录。

## 总评

**优点：**
1. 问题真实且有诊断力。零样本实验给出的负结果干净利落：Qwen2-Audio 在 3N 上 IoU@0.5 F1 = 0.0000、IFR = 0.0006，Music Flamingo F1 = 0.0342，两个 SOTA 音频-LLM 几乎完全无法把流利的音乐回答锚定到音频时间轴上；同时在和弦与和声模式理解上得分为 0.0000。这组数字直接支持了论文的核心动机。
2. 合成管线带来的精确对齐是方法学上的正确选择。MIDI→PianoTeq 渲染使真值 onset/offset 客观无误，配合 IFR 与定位正确性的分离、MergedIoU 与跨度级 F1 的互补（Music Flamingo 的 MergedIoU 0.8944 vs F1 0.0342 的失配被清晰解释为"输出长区间而非精确定位"），诊断粒度远高于一般 QA 式基准。
3. 2B 子集的变量控制（拍号/速度/调式/音程倾向/和声/重复等在生成时采样）使"可归因性"成为可能，微调模型在 2B 上 Qwen3.5-9B（F1 0.9221、MAE 9.34 ms）显著优于 LLaMA-3-8B（0.7937）也说明该基准在受控分布内有足够的区分度。

**主要问题在于**结论的外部效度与产物的可用性：全部素材限于单声部合成钢琴，而音乐定位的真正难点（复调、多乐器、真实录音、长程结构）恰恰被排除在基准之外，"grounding is challenging but learnable"的结论只能在受控分布内成立；grounding 监督对理解的"帮助"在两个骨干上方向不一致，且依赖的 harmonic pattern 概念仅 51 个测试样本、LLM judge 给所有微调模型打出 Global Accuracy 1.0000（明显过宽），使这一探索性结论的证据链薄弱；数据、代码与模型截至评审时点均未发布（GitHub 检索 0 结果），QA 总量因每材料 20 条查询的复制而有所夸大，可复现性当前只停留在纸面描述层面。

## 日报摘要

- **Strength:** 首个具备精确符号-音频对齐的音乐时间定位基准；诊断出 SOTA 音频-LLM 定位近乎失效（Qwen2-Audio IoU@0.5 F1=0.0000、Music Flamingo 0.0342），任务特定训练可将其推至 0.9221（MAE 9.34 ms）。
- **Weakness:** 素材仅单声部合成钢琴、外部效度未验证；数据/代码/模型未发布（GitHub 检索 0 结果），LLM judge 对全部微调模型打出 Global Acc 1.0000、grounding→理解结论依赖 51 样本概念组且跨骨干不一致，可复现与证据链均有缺失。
