# Paper Review: EvoAudio: Recursive Self-Improvement for Audio Understanding

## 论文类型: 方法型

EvoAudio 是一个面向音频理解的闭环自训练系统。每一轮由 DeepSeek-V4-Flash 读取当前 LALM 在 47 类技能上的表现，决定下一轮练什么、难度往哪调；再由 24 个音频工具（Qwen3-TTS、LeVo、FluidSynth、混音、变速变调等）合成波形和题目，答案由构造过程或原始数据标签给出，经声学复测和纯文本探针过滤后用 GRPO 训练，最后在固定的 2,500 题 held-out 集上决定是否晋级。论文在五个骨干上跑 13 轮，报告 MMSU、MMAU-Pro、MMAR 三项平均最高提升 $6.3$ 分。

## 实验结果审查

### 结果到底怎么样

主表是 Table 2。在论文设置中，只有 Qwen2.5-Omni-7B、Audio Flamingo 3、Kimi-Audio-7B-Instruct 三个骨干有完整的对照组，MiMo-Audio 和 MiniCPM-o 4.5 只报了 Base 和 EvoAudio (GRPO) 两行。

三项平均（Avg.）对比如下：

| 骨干 | Base | 最强对照（Static-profile GRPO） | EvoAudio (GRPO) | 对 Base | 对最强对照 |
|---|---|---|---|---|---|
| Qwen2.5-Omni-7B | 59.3 | 62.8 | 65.4 | $+6.1$（$+10.3\%$） | $+2.6$（$+4.1\%$） |
| Audio Flamingo 3 | 58.4 | 60.3 | 62.7 | $+4.3$（$+7.4\%$） | $+2.4$（$+4.0\%$） |
| Kimi-Audio-7B | 53.3 | 58.1 | 59.6 | $+6.3$（$+11.8\%$） | $+1.5$（$+2.6\%$） |
| MiMo-Audio-7B | 58.8 | 无 | 64.2 | $+5.4$（$+9.2\%$） | 无 |
| MiniCPM-o 4.5 | 64.5 | 无 | 65.9 | $+1.4$（$+2.2\%$） | 无 |

对 Base 的增益大部分来自 GRPO 训练本身。Static-profile GRPO 用同样的工具库、同样的每轮 solver 过滤、同样的预算，只把技能配比和难度冻结在 base 模型的画像上，就已经拿到了 $+1.9$ 到 $+4.8$ 分。真正归属于「自适应课程」的部分，是 EvoAudio 与 Static-profile 之间的差，三个骨干上分别是 $2.6$、$2.4$、$1.5$ 分，论文自己给的均值是 $2.1$ 分（Sec. 3.2）。

分 benchmark 看，增益集中在 MMSU。Qwen2.5-Omni 上 MMSU All 从 $61.4$ 到 $71.9$（$+10.5$），MMAU-Pro 从 $56.4$ 到 $60.8$（$+4.4$），MMAR 从 $60.2$ 到 $63.5$（$+3.3$）。我按 Table 2 复算了 Sec. 3.3 的跨骨干均值：MMSU $+6.0$、MMAU-Pro $+5.0$、MMAR $+3.0$。论文给的 MMSU 是 $+6.1$，它用的是 attempt 13，与 Table 2 的最终晋级模型可能不是同一个 checkpoint，差 $0.1$ 在这个范围内。

有几处数字和论文的解释对不上。

第一，Qwen2.5-Omni 的 MMAR Culture 从 $58.9$ 涨到 $69.4$（$+10.5$），是该骨干 MMAR 各子类中涨幅最大的一项。而论文在 Sec. 3.3 说 MMAR 的「semantic and cultural reasoning lies mostly beyond what they [tools] can build」。工具库造不出文化类题目，文化类却涨得最多，论文没有解释。MMAR 全集只有 1,000 题（MMAR 原文摘要），Culture 是其中一个子层，样本更少，这个 $+10.5$ 很可能主要是噪声。

第二，Kimi-Audio 的 MMAU-Pro Sound 从 $37.1$ 涨到 $56.9$（$+19.8$），MiMo-Audio 从 $38.3$ 到 $51.6$（$+13.3$）。两个 base 的 Sound 分数远低于同表其他骨干（45–50），而论文规定「Invalid predictions count as incorrect」。一种可能的理解是，这部分增益有相当比例来自输出格式变得可解析，而非声学感知变强。论文没有报告各模型的 invalid 比例，这一点无法排除。

第三，MiniCPM-o 4.5 的 MMAR Percep. 从 $63.4$ 降到 $60.0$（$-3.4$），MMAU-Pro Speech 和 Music 也小幅下降。在最强的 base 上，方法基本只剩 MMSU 的 $+4.0$。

### 有没有躲开的基线

Table 2 里所有「方法基线」都是作者自己构造的消融式对照（Static-profile GRPO、Pooled GRPO、EvoAudio (SFT)）。没有任何一个外部发表的 LALM 后训练方法进入主表。

按论文提交时间（2026-09）和论文自己在 Introduction 里引用的工作，下面这些应该出现：

| SARI | 2025-04 | 课程式 RL 音频推理，论文在 Intro 里引作 partial adaptation | 骨干同为 Qwen 系 | 否，只引用 |

| AQA-TTRL | 2025-10 | label-free 自适应 RL，Intro 引用 | 骨干相同 | 否，只引用 |
| Audio-Thinker | 2026-01（AAAI 2026） | Qwen2.5-Omni 上的 RL 音频推理强基线 | 骨干相同 | 否 |
| Audio-Zero（2607.20166） | 2026-07 | 音频域 label-free 自演化，最直接的竞争者，论文 Intro 引用并称其「remain fixed throughout training」 | 骨干同为 Qwen2.5-Omni，同样报 MMAR | 否，只引用 |
| AudioRubrics（2608.02831） | 2026-08 | 随训练演化的 reward，Intro 引用 | 未查到开源 | 否，只引用 |

Audio-Zero 是最该比的一项。本仓库评审 `/Users/ihatetheworld555/projects/工具/ihatetheworld555.github.io/_paper_reviews/2026-07-22/2607.20166v1.md` 记录，Audio-Zero 在 Qwen2.5-Omni 上报告 MMAR $66.2\%$（$+10.0$）。EvoAudio 在同一骨干上的 MMAR 是 $63.5\%$（$+3.3$）。两篇的评测协议、prompt 和答案抽取规则不同（Audio-Zero 报的 base MMAR 约 $56.2$，EvoAudio 报 $60.2$），数字不能直接相减，但这个量级差距足以说明不比较是一个缺口。

骨干选择上也有回避。五个骨干都是 7–9B，没有 Qwen3-Omni-30B-A3B，也没有 Step-Audio-R1 一类已经做过音频 RL 的模型。MiniCPM-o 4.5 是五个里最强的 base（Avg. $64.5$），增益也最小（$+1.4$），趋势指向「base 越强、方法越没用」，而更强的骨干恰好没测。

### 增益是否超出评测误差

论文没有报告方差、置信区间、多 seed 或显著性检验。Table 2 和 Table 3 每格都是单次运行。

我按二项分布粗估测试集噪声（这是估算）。MMSU 5,000 题、MMAU-Pro 计分 4,239 题、MMAR 1,000 题，准确率取 $p\approx0.6$ 时，单个模型的标准误分别约为 $0.69$、$0.75$、$1.55$ 分。三项平均的标准误约为

$$
\sigma_{\text{Avg}}\approx\frac{1}{3}\sqrt{0.69^2+0.75^2+1.55^2}\approx0.62\ \text{分}.
$$

其中，分母 3 来自三项等权平均，各项之间视为独立。

这只是测试集采样噪声。RL 训练的 seed 方差没有计入，论文也没有给出任何可以估计它的信息，真实噪声只会更大。

放在这个量级下看：

- 对 Base 的 $+4.3$ 到 $+6.3$ 分远超噪声，可信。MiniCPM 的 $+1.4$ 大约是 $2\sigma$ 测试噪声，再叠加 seed 方差后不稳。
- 对 Static-profile 的 $+2.6$、$+2.4$ 分约为 $4\sigma$ 测试噪声，在单 seed 下方向大概率成立；Kimi 的 $+1.5$ 分约 $2.4\sigma$，加上 seed 方差后无法下结论。
- Table 3 的消融差异在 $0.5$（No retention floor）到 $2.1$（Difficulty fixed）分之间，只在 Qwen2.5-Omni 上跑了一次。retention floor 的 $-0.5$ 和 acoustic verification 的 $-1.3$ 都落在噪声区间内或边缘。
- MMAR 子类（如上面提到的 Culture $+10.5$）样本量更小，单个子类的噪声远大于 $1.55$ 分。

循环评测方面，论文的评测是 MCQ 准确率，没有使用 LLM-as-judge。晋级用的 held-out 集由作者的工具链生成，与三个 benchmark 无关，benchmark 没有参与 checkpoint 选择，这一点是干净的。但论文只保证 held-out 集与训练集无模板、录音、seed 重叠，没有检查训练来源（AudioSet、FSD50K、LibriSpeech、MELD）与 MMAU-Pro、MMAR 的音频来源是否有重叠。

指标挑选方面，MMAU-Pro 排除了 open-ended、spatial、instruction-following 子集，只保留 4,268 题中的 4,239 题。排除理由合理（MCQ 可验证），但这也意味着报告的是 MMAU-Pro 的一个子集。

## 公理审查结果

### 公理一：对象公理
- 判定: ⚠️
- 分数: 7
- 依据: 问题真实。LALM 在语义上强、在声学感知上弱，在 Table 2 的 base 数据里可见：Qwen2.5-Omni 的 MMSU Reason. $79.4$ 而 Percep. 只有 $44.5$，Kimi-Audio 是 $74.3$ 对 $39.0$。人工声学标注贵、强模型标注有上限，这两个动机陈述清楚。扣分在于「recursive self-improvement」的定性超出证据：Sec. 3.3 承认四个骨干的最大增益出现在第一轮，「the curves are close to flat by the end」，模型从未答对的技能 GRPO 打不开。13 轮实际呈现的是一次大跳加缓慢饱和，与「递归自我改进」的说法有距离。
- Wiki 证据: 本仓库 Audio-Zero 评审（2026-07-22/2607.20166v1.md）记录了同一问题在 TREA 等细粒度基准上的 base 弱点，支持问题真实性。OpenAlex 检索确认同期有 Reward-Tilted OPD、Listen Then Reason 等工作在攻同一「声学 grounding」缺口。

### 公理二：识别公理
- 判定: ⚠️
- 分数: 5
- 依据: 内部对照设计较好：Static-profile GRPO 与 EvoAudio 只差课程是否随 solver 更新，Pooled GRPO 只差数据顺序与时机，二者同预算（13 轮 × 64 步 × 16 prompt × 16 response），能隔离出自适应课程的 $2.1$ 分（Sec. 3.2）。但外部方法基线为零。R1-AQA（2025，代码开源）、Omni-R1、AQA-TTRL、Audio-Thinker、Audio-Zero（2026-07）都在 Qwen2.5-Omni 上做过 RL，论文引用了其中多数却一个都没比。也缺一个最小基线：直接拿公开音频 QA 数据（如 AVQA、AudioSkills）跑同预算 GRPO，用来回答「整套合成工具库到底值多少」。MiMo-Audio 和 MiniCPM-o 4.5 只有 Base 对照，五个骨干里有两个无法做归因。
- Wiki 证据: OpenAlex 检索到上述基线条目（随后触发限流）；GitHub 查到 `xiaomi-research/r1-aqa` 328 star、`stepfun-ai/Step-Audio-R1` 701 star。本仓库 Audio-Zero 评审给出其 Qwen2.5-Omni MMAR $66.2\%$，可作量级锚点。free-search 四次检索均返回无关结果。

### 公理三：独立性公理
- 判定: ⚠️
- 分数: 7
- 依据: 评测用三个外部公开 MCQ benchmark，没有 LLM-as-judge 或自家模型打分。晋级与 checkpoint 选择用的是作者自建的 2,500 题 held-out 集，benchmark 不参与选择。答案来自构造过程或原始标签，不依赖模型标注。扣分点两处：第一，没有检查训练音频来源（AudioSet、FSD50K 等）与 MMAU-Pro、MMAR 的潜在重叠；第二，「invalid 计为错误」的规则下，Kimi、MiMo 的 MMAU-Pro Sound 分别涨 $19.8$、$13.3$ 分，格式合规与真实感知提升混在一起，论文未报 invalid 比例。
- Wiki 证据: MMAR 原文摘要确认其 1,000 题来自互联网视频；MMSU 原文摘要确认 5,000 题、47 类任务。未查到 MMAU-Pro 与 AudioSet 的来源重叠数据，此项未能核实。

### 公理四：压缩公理
- 判定: ⚠️
- 分数: 5
- 依据: 系统组件很多：LLM proposer、式 1 的配比重加权（上限 $0.06$、$12\%$ 保留）、式 2 的难度控制（目标通过率 $p^\star=0.5$）、24 个工具、声学复测、Whisper 校验、纯文本探针、4 次 rollout 的 1–3 正确过滤、双 checkpoint 晋级。Table 3 显示真正起作用的是难度自适应（固定难度 $-2.1$）和难度过滤（保留全部已验证题 $-1.8$），这两者都是 DAPO / 学习进度课程里的已知做法；均匀配比只掉 $-1.7$，保留下限只掉 $-0.5$。DeepSeek-V4-Flash proposer 本身没有被消融，换成「按错误率加权」这类规则能否达到同样效果，论文没有回答。
- Wiki 证据: 论文自己引用 Matiisen 2019（teacher-student curriculum）和 DAPO（零方差组过滤）作为式 1 与过滤规则的来源。无额外检索。

### 公理五：效用公理
- 判定: ⚠️
- 分数: 5
- 依据: 对 Base 的增益真实：Avg. $+4.3$ 到 $+6.3$（Qwen、AF3、Kimi、MiMo），远超约 $0.62$ 分的测试集噪声估算。但对最强内部对照只多 $1.5$ 到 $2.6$ 分，单 seed、无方差。在最强的 base（MiniCPM-o 4.5）上只有 $+1.4$，且 MMAR Percep. 下降 $3.4$。没有外部方法对比，读者无法判断这套工具链是否打得过「拿公开数据跑 GRPO」这样便宜得多的替代方案。Qwen2.5-Omni 上最终 MMAR $63.5$，低于 Audio-Zero 自报的 $66.2$（协议不同，仅作量级参考）。
- Wiki 证据: 本仓库 Audio-Zero 评审（2026-07-22/2607.20166v1.md）记录 Audio-Zero 仅用 2k 无标注对比对在 Qwen2.5-Omni 上 MMAR $+10.0$。OpenAlex 后续检索因限流失败。

### 公理六：新颖性公理
- 判定: ⚠️
- 分数: 5
- 依据: 论文称首次在一个闭环里同时演化模型、波形、题目和难度。组成部分都有出处：propose-solve 自博弈框架来自 Absolute Zero，带标签的程序化声音合成来自 Scaper（2017），学习进度课程来自 Matiisen（2019），零方差组过滤来自 DAPO，训练用 GRPO。音频域内，Audio-Zero（2026-07）已经做了 label-free 自演化，AudioSkills 做了按技能和难度组织的合成 QA。EvoAudio 的增量在于把「答案由构造保证 + 渲染后声学复测」做成一个覆盖 47 类题型的工具库，并接上随 solver 更新的课程。这是有工程价值的组合，方法层面的新意有限。
- Wiki 证据: OpenAlex 确认 Audio-Zero（2026-07-22）、AudioRubrics（2026-08-03）早于本文约 1–2 个月；本仓库 Audio-Zero 评审已将其新颖性判为「跨域迁移」。

### 公理七：可复现公理
- 判定: ⚠️
- 分数: 4
- 依据: 论文只给了 demo 页（jensenyx.github.io/EvoAudio.github.io，HTTP 200），页面链接只指向 arXiv；GitHub 上唯一同名仓库 `JensenYX/EvoAudio.github.io` 是 demo 站点本身。代码、工具库、2,500 题 held-out 集、训练出的权重均未发布。proposer 是 DeepSeek-V4-Flash API，结果依赖该闭源服务的行为。超参数给得比较全（lr $1\times10^{-6}$、KL $0.02$、温度 $0.9$、4 节点 × 8 H800、每轮 64 步），但式 2 的步长 $\eta$、各技能的 $c_{\min}/c_{\max}$、47 类题型的具体模板与声学阈值没有给出。
- Wiki 证据: `gh search repos "EvoAudio"` 只返回 demo 站点仓库；抓取 demo 页确认无代码链接。

## 总评

论文的优点在三处。第一，问题选得准，声学感知弱于语义理解在五个骨干的 base 数据里都看得到。第二，「答案由构造过程决定、渲染后再复测」这条思路给音频 RL 提供了不依赖强模型标注的可验证奖励，Table 3 中去掉声学验证后 Var. 从 $53.8\%$ 升到 $57.2\%$，Avg. 却从 $65.4$ 降到 $64.1$，说明复测确实挡住了一批错误奖励。第三，内部对照设计规整，Static-profile 与 Pooled 两个同预算对照把自适应课程的贡献单独隔离到了约 $2.1$ 分。

主要问题在于外部证据缺失。主表没有任何一个外部方法基线，R1-AQA、Omni-R1、AQA-TTRL、Audio-Zero 等同骨干 RL 方法论文都引用了却没有比较；全部结果是单 seed，自适应课程带来的 $1.5$ 到 $2.6$ 分只比估算的测试集噪声高 2–4 倍，还没算 seed 方差；最强骨干上增益只剩 $1.4$ 分，更强的 Qwen3-Omni 级骨干没有测。部分大幅增益（Kimi MMAU-Pro Sound $+19.8$、Qwen MMAR Culture $+10.5$）与论文自己对工具覆盖范围的解释相矛盾，格式合规可能占了一部分。代码、数据、权重都没有发布。

## 日报摘要
- **Strength:** 用构造即答案的 24 工具合成闭环做 GRPO，在 Qwen2.5-Omni 上把 MMSU 从 $61.4$ 提到 $71.9$，三项平均 $+6.1$，且同预算下比冻结课程的对照多 $2.6$ 分。
- **Weakness:** 主表零外部方法基线（R1-AQA、Audio-Zero 等同骨干 RL 方法均未比），全部单 seed，课程本身的 $1.5$–$2.6$ 分增益缺少方差支撑，代码与数据未发布。
