## 公理审查结果

### 一 对象公理 — ✅ 9/10
**依据**：研究对象定义精确且全程自洽：13 个 NAC（6 个经典 RVQ + Mimi 混合 RVQ、3 个单码本大词表 VQ、3 个非 VQ/标量/焦点/语义量化）× 3 语料（LJSpeech/VoxCeleb/TrIJEK，各约 10 小时）× 3 声学条件（干净/0 dB 白噪声/0 dB DEMAND 真实噪声），共 117 个 cell。每一步处理都显式化：取 RVQ 第一级（用 KS 距离验证：0.012±0.007，显著低于后续各级的 0.049-0.110）、相邻去重（量化其对 α、β 的影响，Cohen's d≈0.5）、族条件化 n-gram 阶数、5K-500K token 分块估计、拟合有效性保障（α 截断在 3 时重拟合、V/N>0.9 时判拟合无定义）。噪声波形对所有编解码器固定同一种子生成，保证可比性。
**Wiki 证据**：第3节方法论与第4节实验设置表（13 个编解码器的词表规模、采样率、码率逐项列出，如 XCodec2 词表 65,536、FocalCodec 0.65 kbps）；第5节估计可靠性专章。

### 二 识别公理 — ⚠️ 6/10
**依据**：识别工作在描述性研究里相当扎实：三因素方差分析（meta-category × corpus × condition，Type-II 平方和，η² 效应量，表VIII）加编解码器随机截距混合模型（组内相关 0.46-0.96，噪声与 meta×condition 交互对每个指标 p≤0.001）；JSD-质量相关性做了三层稳健性检查——剔除两个非 VQ 编解码器后 UTMOS 关联仍显著（Pearson −0.68, p=0.029），逐个剔除单编解码器系数移动不超过 0.10；collapse/explosion 阈值做了死区减半/加倍敏感性分析（RVQ 组内 15/21 vs 14/11 collapse）。扣分点有三：(1) JSD-质量相关基于 12 个编解码器均值，n=12 统计功效有限，且白噪声下 MCD 的 Pearson 0.62 在剔除非 VQ 后反号为 −0.27——同一关联在不同子群上翻号，说明该维度识别不稳；(2) ANOVA 的 13 个编解码器为固定单元，η² 只能作描述性解读（论文自己承认）；(3) collapse/explosion 的 15+18 个 cell 计数依赖人工选取的死区阈值，定义域内连续变化，识别强度受定义选择制约。
**Wiki 证据**：表VIII（η²：H 上 meta-category 0.551 最高、corpus 全线近 0）；表X（白噪声下 UER 的 Spearman −0.73 与 UTMOS 的 Spearman 0.06 并存，说明指标间识别结论分裂）；第8节阈值敏感性段落。

### 三 独立性公理 — ⚠️ 5/10
**依据**：核心混杂未被解耦，且论文诚实列出：词表规模与架构族/码率/训练目标完全混杂（RVQ 全部 1,024-2,048 词表、单码本全部 ≥4,096），"低 α 属于 RVQ"与"大词表使拟合指数变陡"两种解释在现有设计上无法区分（第9C节的采样论证只是理论推测）；自动质量估计器（UTMOS、Whisper dCER）可能携带与架构相关的偏置；仅两种噪声、单一 0 dB SNR，SNR 扫描留作未来工作；编解码器固定为黑盒，无再训练干预。正面项：语料因子被有意控制（三语料上同一批编解码器、同一噪声波形），"语料几乎不解释方差"（α 的 η²=0.003、H 的 η²=0.000）这一阴性结论在同设计内是干净的。
**Wiki 证据**：第9D节局限原文逐条承认词表混杂、SNR 单点、估计器偏置、S3Tokenizer 无解码器（JSD-质量仅覆盖 12 个）；第5节固定阶数敏感性（n=1 时 η²_meta=0.05 p=0.37 vs n=2 时 η²=0.63 p<0.001）显示结论对 n-gram 阶数选择敏感，进一步说明因素未完全分离。

### 四 压缩公理 — ⚠️ 6/10
**依据**：三条结论（语料可忽略且因素主导呈指标依赖；单阶 JSD 是 DEMAND 噪声下的无解码器诊断；collapse/explosion 按架构聚集）高度可压缩，"架构条件化协议"本身即是一句话可复述的操作规范。扣分在于指标动物园偏宽：Zipf α、Heaps β/K、熵 H、冗余 R、占用率、JSD、repetition rate、transition entropy 共 8 类指标，而其中 Δα 的跨噪声鲁棒性排名与 UER 几乎正交（ρ=−0.04, p=0.90），KS 与 β 的ANOVA 残差占比达 0.70-0.74（即绝大部分方差未被任何因素解释），这些低产出的维度稀释了贡献密度；族条件化 n-gram 阶数（13 个编解码器中仅 8 个与语料均值最优一致、Mimi 偏差为 2）使跨族对比本身即受限，压缩后的通用结论覆盖面打折。
**Wiki 证据**：表IV（固定阶数下 α 族间差异从 η²=0.05 翻到 0.63）；表VIII（KS/β 的残差 η² 0.704/0.745）；第7节 UER cell 均值 0.66-1.00（天花板效应使其信息量有限）。

### 五 效用公理 — ✅ 7/10
**依据**：对构建 codec-based LM 的从业者有直接可用产出：(1) 无解码器 JSD 诊断——在 DEMAND 噪声下与 UTMOS 的 Pearson −0.76/Spearman −0.65，且适用于无解码器的语义 tokenizer（S3Tokenizer），这是唯一能对其出质量估计的通道；(2) 架构条件化退化签名——collapse 聚集在 RVQ×白噪声（14/21 cell）、explosion 聚集在 RVQ×DEMAND（13/21）加 S3Tokenizer（4 cell），单码本 VQ 以占用率下降 33-75 个百分点而无任一签名的方式退化——排查管线可直接按架构路由；(3) 明确纠偏了"α≈2 是普适目标"的解读，规定跨编解码器比较必须固定 meta-category、n-gram 阶数与词表规模；(4) 拟合有效性保障（截断重拟合、V/N>0.9 判废、500K token 参考样本、α 在 5K token 时偏差 1.06 超出全距的最小样本警示）可直接移植到任何 token 统计研究。限制效用宽度的因素：诊断仅在 0 dB 两个噪声类型上验证，JSD-质量关联在白噪声下失效（UTMOS Pearson 0.15），对高 SNR 或其他失真类型的适用性未知。
**Wiki 证据**：表X（JSD-质量全系数矩阵，DEMAND 列与白噪声列的对比）；表XI（78 个 cell 的三签名分组计数）；第6节鲁棒性排名的指标依赖性（ρ=0.81/0.65/−0.04）。

### 六 新颖性公理 — ⚠️ 7/10
**依据**：概念框架（token 上的 Zipf/Heaps/熵）借自已确立的先行工作：VQ-VAE 图像 token（Chan et al.）、HuBERT token（Takamichi et al.）、以及直接前驱 2509.01390（6 个 RVQ 编解码器、干净语料）。本文的增量真实且非平凡：(1) 首次把 NAC token 分布分析扩展到噪声条件——相关工作部分明确指出此前无系统性研究（经 arXiv API 检索佐证）；(2) 覆盖从 RVQ 到非 VQ 的 13 个编解码器、三种量化元类别，推翻了单码本不出现任一签名、非 VQ 也会 explosion（S3Tokenizer 4 cell）等无法从前驱推出的发现；(3) JSD 作为分布层面诊断与 MCD/UTMOS 的条件性关联（DEMAND 下成立、白噪声下不成立）是新的实证格局；(4) "族条件化 n-gram 阶数"修正了前驱"3-gram 最优"的普适化表述。单项组件均为标准统计工具，新意在于实验设计与条件性结论。
**Wiki 证据**：第1节与前驱 [9] 的逐点对比（覆盖面、条件、结论三处扩展）；第8节表XI 的架构-噪声聚集格局为全文最具新颖性的实证发现；arXiv API 检索确认 2509.01390 为唯一直接前驱。

**依据**：方法文档化程度高：编解码器清单完整（词表、采样率、码率逐项给出）、数据抽取基于公开的 Codec-SUPERB、语料全部公开（LJSpeech/VoxCeleb/TrIJEK/DEMAND）、评估工具全部公开（Whisper-large-v3、UTMOS、WORLD+DTW、Praat、powerlaw 库）、噪声生成固定种子且对全部编解码器共用、样本规模（匹配的 500K token 参考样本）与拟合保障规则齐备，理论上可依文重实现。扣分点：arXiv 页与正文均未提供代码或数据链接（GitHub 多组检索 0 命中），噪声波形、分块方案、MCD 的 RMS 重缩放细节等只能依赖文字描述重建；S3Tokenizer/FocalCodec 等部分编解码器的具体获取渠道未在可见正文中给出；无第三方复现记录。 TASLP 在审稿件不强制放码是常见情形，但按本文 own standard（一个"协议"型贡献的可迁移性恰恰依赖工具化）扣分成立。

## 总评

**优点**：(1) 问题定位有真实空隙——NAC token 的语言统计规律研究此前停留在干净语料 + RVQ 单一族（2509.01390），本文把架构谱系（13 个、三种元类别）与噪声条件（白噪声/DEMAND 各 0 dB）两个维度首次补齐，发现"语料几乎不解释方差（η²≤0.005）而条件与架构按指标分化主导"这一非平凡格局；(2) 统计纪律严格——拟合有效性保障、RVQ 第一级验证（KS 0.012 vs 0.049-0.110）、去重效应量化（d≈0.5）、Type-II ANOVA 加混合模型双重检验、JSD 相关的逐点剔除与子群稳健性检查（系数移动 ≤0.10），在同类描述性研究中超出平均水准；(3) 无解码器 JSD 诊断在 DEMAND 下 r=−0.76（UTMOS）且适用无解码器的 S3Tokenizer，是少数能触及语义 tokenizer 质量的免解码通道；(4) collapse/explosion 按架构-噪声聚集的签名（RVQ×白噪声 collapse 14/21、RVQ×DEMAND explosion 13/21、单码本全中性但占用率掉 33-75 点）直接可转化为按架构路由的退化排查规程。

主要问题在于混杂未解耦与关键关联的脆弱性：词表规模与架构族/码率完全混杂，"低 α 属于 RVQ"与"大词表使指数变陡"两个解释无法分离，论文只能以理论采样论证带过；JSD-质量关联在白噪声下失效（UTMOS Pearson 0.15）且 MCD 系数在剔除非 VQ 后从 0.62 反号为 −0.27，使"JSD 是分布层诊断"这一核心卖点的适用域收窄到单一噪声类型；相关分析仅 12 个编解码器均值点，η² 基于固定单元只能描述；仅 0 dB 单一 SNR 使结论对强度维度的外推完全未知；全部指标仓库均无代码发布，协议型贡献的可迁移性依赖第三方自行重实现。此外 KS 与 β 的方差约七成落在残差项，说明现有因素框架对这两个指标的解释力接近于零，指标集合有精简空间。

## 日报摘要

- **Strength:** 首次将 NAC token 语言统计扩展到 13 编解码器 × 3 噪声条件（117 cell），发现语料几乎不解释方差（η²≤0.005）而架构-噪声按指标主导，单阶 JSD 在 DEMAND 下与 UTMOS 相关 r=−0.76（逐点剔除后系数移动 ≤0.10），collapse/explosion 签名按架构聚集（RVQ×白噪声 14/21、RVQ×DEMAND 13/21）。
