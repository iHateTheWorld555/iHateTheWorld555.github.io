## 公理审查结果

### 一、对象公理 — ✅ 9/10
**依据**：研究对象清晰且边界自洽：吉他 tab 转录中"同一音高可在多个弦-品位置演奏"的歧义消解问题，并以可玩性（playability）为核心目标。任务规格有具体数字：每事件为 6 弦、每弦 F = M_f+2 类（muted/open/品 1..M_f）离散标签；音频窗 100 ms 切成 T=7 帧、最多 2 个同时事件；共 45,972 个训练样本。明确声明适用范围：仅标准调弦、无效果器、无 capo、无电吉他音色（Limitations 主动承认）；评价指标明确（PP/PR/PF、TP/TR/TF、TDR，并新增 FNR/FPR 分开统计漏检与误报）。
**Wiki 证据**：方法节表示定义、数据节 45,972 样本数与窗口规格、Limitations 节范围声明。

### 二、识别公理 — ✅ 8/10
**依据**：论文将 tab 转录性能短板归因于"分类式目标忽略音高类、把位、五度圈、弦相似性、手跨距五类音乐-物理约束"，并用单损失消融直接验证每个约束的作用：在 GOAT 上（Table 2），无辅助损失基线 TF 0.740；仅加 L_pos 即把 TR 从 0.724 提到 0.785、FNR 保持最低 0.145；L_pc 把 PP 从 0.765 提到 0.813 但 TR 降到 0.715；L_CoF 最弱（PP 反降至 0.722）；L_str 与 L_span 各带来 TF 0.772/0.773；组合 +L_aux 达 TF 0.795、FPR 最低 0.022。识别的机制与消融结果一一对应（含负结果：CoF 单独反而有害），"识别→验证"闭环成立。
**Wiki 证据**：Table 2 九行消融的完整数字链（含每个损失的独立效应方向）。

### 三、独立性公理 — ⚠️ 5/10
**依据**：正项：两个公开数据集独立评测（GuitarSet 六折 CV 沿用 FretNet 预处理、GOAT 官方划分），指标采用领域标准（Wiggins & Kim 一系）且新增 FNR/FPR 提升了诊断粒度。扣分项：(1) 基线只有两个（TabCNN 2019、FretNet 2023），在 2026 年的论文中缺少任何 2023 年后的近期对照（如基于 transformer 或其他生成式的 tab 转录工作），且未说明基线是否在统一特征/训练预算下重训；(2) 全部结果无统计显著性检验、无多次运行方差；(3) GOAT 上 TDR 三方均 ≈0.99，该指标已饱和、区分力弱，作者未讨论；(4) 无任何人类听感/可玩性主观评测——"playability-aware"的核心主张完全由代理损失与指标间接支撑；(5) 论文自述 GOAT 标注存在 Let Ring 缺标（Fig. 3 手工谱分析发现），即评测数据本身带噪且此噪声系统性偏向惩罚长音延续，作者虽诚实披露却未量化其影响。
**Wiki 证据**：Table 1/2/3 全部指标、Fig. 3 与 GOAT 标注缺口讨论、Limitations 节。

### 四、压缩公理 — ⚠️ 6/10
**依据**：正向：核心表示紧凑优雅——把离散弦-品标签经每弦 learned embedding 拼成连续事件向量，使扩散模型可以作用于离散结构目标，一页讲清；架构为标准 1D U-Net + v-prediction + DDIM，无多余组件。负向：(1) 五个辅助损失存在明显冗余——L_pc 与 L_CoF 都作用于 12 维音高类向量（Jaccard 距离 vs 加权均值圆距），消融显示 L_CoF 是唯一单独有害的损失，其存在价值需要组合实验进一步辩护；(2) 六个 λ 权重（λ_pos=1、其余 0.1、交叉熵 0.1）为手工设定，无权重敏感性分析；(3) M_span=6 品的阈值直接取自 GOAT 观测最大值，在 GuitarSet 上因 capo 演奏而置 λ_span=0——同一模型族在不同数据集上损失配置不同，规则由数据集特例驱动，增加认知负担；(4) 条件特征四件套（STFT/谱流/brightness/原始波形）的必要性靠 Table 3 逐一消融补证，正文对其设计动机着墨少。
**Wiki 证据**：五个损失定义、λ 配置段、Table 2（L_CoF 单独 PP 0.722 为全场最低）与 Table 3 条件消融。

### 五、效用公理 — ⚠️ 7/10
**依据**：正向：解决的痛点真实（吉他手需要可弹的指法序列而非仅音高）；GOAT 上全面领先两个基线——TF 0.795 vs FretNet 0.662 / TabCNN 0.656，TP 0.822 vs 0.681/0.744，TDR 0.993；计算效率是突出卖点：15M 参数但每前向仅 341M FLOPs，为 TabCNN 的约 1/10、FretNet 的约 1/51，RTX 3090 上 RTF 0.67 接近实时。负向：(1) GuitarSet 上音高精确率有明显代价——PP 0.855 vs FretNet 0.919，作者承认是精度-召回权衡，但对以"找错音"为痛点的转录用户这是实际可用性损失；(2) 100 ms 窗口、最多 2 个同时事件的极短上下文意味着模型看不到乐句级指法连续性，而可玩性本质上是序列性质（指法转换平滑），更长相位作者仅在 Future Work 中以"preliminary experiments suggest this helps"带过、无数字；(3) 严格限于标准调弦、无 capo/效果器/电琴，覆盖真实使用场景有限；(4) FNR/FPR 改善（0.145/0.022）虽好，缺从指标到"减少 guitarist 手工修正量"的转换论证。
**Wiki 证据**：Table 1/2 主结果、效率段（FLOPs/RTF）、Limitations 与 Future Work 节。

### 六、新颖性公理 — ⚠️ 7/10
**依据**：两个贡献点的新颖度：(1) 据论文自述这是首个面向 tab 转录的扩散模型——将离散 tab 目标嵌入连续空间做 v-prediction 扩散是本子领域的新组合，"discrete-to-continuous embedding for diffusion"思想在语音/符号生成领域已有先例（论文也引用了相关扩散实践），属方法迁移而非范式创新；(2) 五个音乐理论辅助损失（音高类 Jaccard、五度圈圆距、把位距、弦相似 Jaccard、手跨距铰链惩罚）是本文最有辨识度的部分——把可玩性显式写进训练目标，此前 tab 转录文献（TabCNN/FretNet）均无此设计；但单个距离度量均为音乐信息检索中的经典构造，贡献在组合与落地。因 Semantic Scholar/OpenAlex 均被拒（限流/欠费），无法独立核验"首个扩散 tab 转录"的新颖性主张是否成立，此处如实记录为未验证。整体为"新组合 + 一个有消融支撑的新损失族"，中等偏上新颖性。
**Wiki 证据**：贡献声明、五损失定义节、Table 2 消融证明损失族有效；GitHub README 与论文归属一致。

### 七、可复现公理 — ⚠️ 6/10
**依据**：正向（实测核验）：代码仓库公开且覆盖完整流水线（数据预处理 4 个脚本 + 训练/推理/评测源码 + requirements.txt + run.sh）；论文给出全部关键超参（AdamW 3e-4 余弦退火、batch 128、1000 epochs、channel 64、DDIM 采样、逐项 λ），数据集（GuitarSet、GOAT）公开可下载，GuitarSet 六折与 FretNet 预处理对齐保证可比。负向（实测核验）：(1) README 明确承诺 `./weights` 文件夹存放预训练模型，但该路径实际 404——论文最核心的可复现资产（训练好的模型）缺失，想直接用模型或做公平对比只能从头重训（1000 epochs）；(2) 仓库无 license 文件，复用边界不明；(3) 社区信号极弱（2 stars、0 forks、0 issues），无第三方验证；(4) 最后推送 2026-08-11 早于论文挂出（08-31），此后无维护迹象。
**Wiki 证据**：gh api 实测 repo 元数据与 contents 列表；README 承诺与 weights/ 404 的矛盾。

## 总评

**优点**：这是一篇对象定义清楚、消融扎实的贡献较大的方法型论文。其一，它抓住了 tab 转录的真实缺口——分类式方法不编码指法的音乐-物理约束——并把缺口转成五个可微辅助损失，其中每个损失都有独立消融且不回避负结果（L_CoF 单独加入反而降 PP 至 0.722），组合 +L_aux 在 GOAT 上把 tab F 值从 0.740 推到 0.795、FPR 压到全场最低 0.022，证据链完整。其二，计算效率论点有说服力：15M 参数只付出 341M FLOPs/前向，比 TabCNN 少一个数量级、比 FretNet 少约 50 倍，RTF 0.67 接近实时，为"扩散模型也能做轻量判别任务"提供了实例。其三，诚实度较高：主动披露精度-召回权衡、GOAT 的 Let Ring 标注缺口（Fig. 3 手工谱例佐证）、capo 演奏导致 λ_span 置零等细节，训练配方（六折 CV、全部 λ、优化器设置）完整到可照抄。

主要问题在于评测独立性与可复现闭环两端。评测上基线过老过少（仅 2019 的 TabCNN 与 2023 的 FretNet），2023 年后的同类工作缺席且未说明基线是否公平重训；全部结果无显著性检验与运行方差；GOAT 上 TDR 三方均 ≈0.99 已失去区分力；最关键的是"playability-aware"这一核心主张没有任何人类听感或 guitarist 评审支撑，完全依赖代理指标。数据层面 GOAT 的 Let Ring 缺标会系统性惩罚长音延续，作者发现后未量化它对 Table 2 各行的影响幅度。可复现上，README 承诺的 `./weights` 预训练权重实测 404，仓库无 license，核心资产缺失使复现成本陡增；"更长上下文有利可玩性"的初步实验只有一句话、无数字。本审稿未能通过 Semantic Scholar 与 OpenAlex 独立核验该文引用情况与 2023 年后基线版图（两 API 分别 429 限流与预算耗尽），"首个扩散 tab 转录模型"的新颖性主张以论文自述为准，此处如实记录。

- **Strength:** 首个（据论文自述）面向吉他 tab 转录的扩散模型 Noise2Fret，五个可玩性辅助损失经单损失消融逐一验证，GOAT 上 tab F 从 0.740 提至 0.795、FPR 最低 0.022，且每前向仅 341M FLOPs（TabCNN 约 1/10、FretNet 约 1/51），RTF 0.67 接近实时。
