## 公理审查结果

### 一 对象公理 — ✅ 9/10
**依据**：研究对象定义清晰且全程自洽：学习型主观感知预测器（AnimeScore/UTMOS/Likability/VAD-Arousal 四轴）作为 GRPO 奖励用于 codec-based TTS（Llasa-1B-Multilingual + XCodec2）时何时保持与人类听者对齐。论文提出「预测器–轴–基模型三元组」作为分析单元，四条奖励轴各自的实现、归一化方式（p̃ 变换）和训练数据全部明示。CER-zone 奖励模板（CLEAN ≤0.10 加 0.5 / FEASIBLE ≤0.30 原值 / VIOLATE >0.30 罚 −1.0）公式化定义，消除歧义。
**Wiki 证据**：正文公式(1)与第3节逐条定义；表5给出基模型输出上三个预测器的分数分布（AnimeScore 均值 −0.39/Std 1.53，UTMOS +3.08/Std 1.01，Likability +4.20/Std 0.44），说明作者先量化了奖励信号在基分布上的统计特性再用于优化。

### 二 识别公理 — ⚠️ 7/10
**依据**：人类识别层面做得相当规范：Lancers 日本众包，每轴 50 对 × 每对 5 评分者，GRPO-vs-Base 的 HWR/MWR/一致率分别为 AnimeScore 80.0/88.0/88.0、UTMOS 62.0/74.0/80.0、Likability 36.0/56.0/76.0。奖励差距逻辑回归基于 1000 票/200 对：奖励差距 β=+0.657、OR=1.93、95% CI [1.38, 2.70]、p<.001，CER 差距不显著（OR=0.96, p=.83），Wald 检验拒绝两斜率相等（p=7.4×10⁻³）。这能识别「平均迁移存在且与残留可懂度差距无关」。扣分点：分轴校准异质——Likability（OR 2.98）与 UTMOS（OR 3.15）显著，AnimeScore 正斜率但不显著；Likability 轴人类 HWR 仅 36%（机器指标 +0.17 却未转化为人类偏好），即轴内识别在部分轴上失效。每种人工条件仅约 10 名听者、50 对，统计功效有限。
**Wiki 证据**：表3、表4、表12；第5.3节显式讨论分轴校准异质性；附录报告排除残留 CER 违规后 HWR 变化幅度 ≤4.5pp（AnimeScore +1.9、UTMOS −2.1、Likability −4.5），结论稳健。

### 三 独立性公理 — ⚠️ 5/10
**依据**：论文自己承认无法解耦：所有结论绑定单一基模型（Llasa-1B）、单一编解码器（XCodec2）、单一解码配置、固定奖励架构选择（如 AnimeScore 用 WavLM-base+BiLSTM+RankNet），无多 seed 训练。分轴结果（如 Likability的机器-人类脱钩）可能由奖励模型训练质量、感知轴性质或基模型分布任一因素驱动，论文将结论限定为「预测器–轴–基模型三元组」的描述性发现并明确否认因果解释——这是诚实的处理，但意味着发现的外部效度依赖未验证的泛化假设。对照实验设计上有加分项：GRPO 与 Best-of-8 在同一奖励门（CER-zone）下公平比较。
**Wiki 证据**：第7节局限性原文承认「无法完全解耦奖励架构、感知轴与基模型分布」；表14/15显示 KL 系数 β 从 0.050 自适应升至 0.082、1400 步后 raw AnimeScore 继续上升而约束感知验证奖励下降（violation 0.24→0.31），提示训练动态与奖励信号的纠缠尚未被分离。

### 四 压缩公理 — ✅ 8/10
**依据**：核心方法贡献高度压缩：CER-zone 三段式奖励模板一句话可复述，四条奖励轴全部复用现成或轻量组件（UTMOS22-strong、MSP-Dim 现成；WavLM-base+分类/回归头轻量训练，Likability 测试 SRCC 0.712/LCC 0.703），无冗余模块。诊断部分压缩为四条可操作的筛查启发式。不足在于实验矩阵略宽（first-shot/CER-retry 两种协议 × 3 run × 多表 + 英文辅助实验 + VAD-Arousal 负例诊断），部分附录分析（表14/15 的 KL 轨迹）对主结论贡献有限。
**Wiki 证据**：第4节方法约一页即完成全部形式化；表2显示 Zone-CER 约束相对 Base 的核心增益集中在单表（AnimeScore ΔTarget +1.35/CER中位 0.054/violation 16.0% vs Base 0.058/24.0%）。

### 五 效用公理 — ✅ 8/10
**依据**：对从业者直接可用：(1) 明确了 GRPO 不应默认优于推理期重排——Best-of-8 在机器指标上几乎追平（AnimeScore +1.21 vs +1.35、UTMOS +0.47 vs +0.49、Likability +0.14 vs +0.17），人类感知上 HWR 52.0/46.0/48.0 接近随机，这纠正了「上 RL 就是更强」的常见误判，并给出「GRPO 是把奖励选择行为摊销进策略」的正确定位；(2) 四条筛查启发式（小规模 A/B 校准、基分布分数检查、域覆盖、区域内信号与惩罚比）可在投入多奖励后训练前廉价执行；(3) CER-zone 约束被消融证明必要：移除后 UTMOS run 中位 CER 从 0.074 恶化到 0.154；(4) 各奖励不可互换的结论（对角线：ΔAS +1.353 / ΔLikab +0.167 / ΔUTMOS +0.485）直接指导奖励选型。局限：范围窄（动漫风格、日文、1B 模型、单卡 H100、每步约 115 秒），对工业级大模型场景的迁移价值需自行验证。
**Wiki 证据**：表2/表3（GRPO vs Best-of-8 人类对比）、第6节四项诊断启发式、消融表（Target-only vs Zone-CER）。

### 六 新颖性公理 — ⚠️ 7/10
**依据**：TTS 后训练用人类/感知反馈的先行工作明确存在：2406.00654（零样本 TTS 人类反馈）、2407.02243（RIO-RLHF）、2505.04113（可懂度偏好对齐）、2509.18928（TTS 扩散 DPO）；2606.21458 已把感知奖励用于语音增强语言模型后训练。本论文的新意在于问题重构：把「主观预测器奖励何时与人类对齐」作为被研究对象，将 RL 视为待诊断的对齐机制，超越以往把 RL 单纯当提分手段的做法——据此产出三块此前未见的内容：(1) 同一奖励门下 GRPO 与 Best-of-N 的人类感知对照；(2) 区分平均迁移与轴内校准的奖励差距逻辑回归框架（含 CER 混淆控制）；(3) 预测器–轴–基模型三元组的报告规范。单项技术组件均非首创，组合与实证结论有增量。arXiv API 检索「subjective reward + TTS」仅命中本文与 DMOSpeech 2（其针对客观指标），佐证该问题切入尚属空白。
**Wiki 证据**：摘要与第1节的问题陈述；表3 GRPO-vs-Bo8 的 52.0/46.0/48.0 HWR 是论文最具新颖性的数据点；第7节对三元组解读的明确定位。

### 七 可复现公理 — ✅ 8/10
**依据**：独立核查通过：GitHub 仓库 sizigi/animeGRPO 真实存在（Apache-2.0，training/evaluation/data/docs 齐备，2026-08-28 创建、09-02 仍在维护），论文承诺开源代码、prompt、音频样本、奖励分数全部兑现方向明确，另有 sizigi.github.io/animeGRPO 音频演示。训练配置完整到可复刻级别（verl + vLLM、K=4、β 初始 0.05 目标 KL 0.05、lr 5×10⁻⁷、batch 16、单张 H100、每步约 115 秒含 Whisper large-v3 门控）。扣分点：Likability 奖励依赖 CocoNut-Humoresque 数据集、VAD-Arousal 依赖 MSP-Dim，受第三方许可约束无法重分发；无多 seed；900/100/50 条日文 Wikipedia prompt 的划分细节依赖仓库核实；0 star 意味着尚无第三方复现记录。
**Wiki 证据**：第8节开源声明与 CC BY-NC-SA 4.0 数据许可；附录训练/评估超参数表；GitHub API 核查结果（见事实锚点）。

## 总评

**优点**：(1) 问题定位准确且诚实——把 RL 是否优于推理期重排这个从业者真正关心的问题当作研究对象，并给出 Best-of-8 人类感知上与 GRPO 无显著差异（HWR 52.0/46.0/48.0）这一反直觉但有用的实证结论；(2) 统计报告规范，奖励差距逻辑回归给出完整 OR 与 95% CI（1.93 [1.38, 2.70]）并用 Wald 检验分离平均迁移与轴内校准，且主动控制了残留 CER 混淆；(3) CER-zone 约束简单有效且被消融验证（移除后中位 CER 从 0.074 恶化到 0.154）；(4) 各主观奖励不可互换（对角线 Δ +1.353/+0.167/+0.485）与四条选型诊断对后续多奖励语音后训练有直接指导价值；(5) 开源完整，代码仓库经独立核查真实可用。

主要问题在于外部效度与识别深度不足：全部结论绑定单一 1B 基模型、单一编解码器与日文动漫域，无多 seed、无跨基模型验证，论文自己承认只能按「预测器–轴–基模型三元组」作描述性解读；分轴识别结果异质，AnimeScore（论文的核心轴，机器增益最大 +1.353）在奖励差距分析中斜率为正但不显著，Likability 出现机器指标 +0.17 与人类 HWR 仅 36% 的脱钩，说明「主观预测器与人类对齐」这一核心命题在自身最关注的轴上尚未被完全识别。此外，人类评估每轴仅 50 对、约 10 名听者，且英文辅助实验仍使用同一日本听者池，跨语言迁移证据力度有限；奖励模型的域依赖（WavLM+BiLSTM 在 900 条 Wikipedia prompt 上训练）与感知轴的解耦未做任何控制实验。

## 日报摘要

- **Strength:** 在同一 CER-zone 奖励门下首次系统对照 GRPO 与 Best-of-8 的人类感知差异（HWR 52.0/46.0/48.0，接近随机），并用 1000 票奖励差距逻辑回归（OR=1.93, 95% CI [1.38, 2.70], p<.001）证明主观奖励平均迁移存在且与残留 CER 混淆无关，给出四条可操作的多奖励选型诊断。
- **Weakness:** 所有结论绑定单一 Llasa-1B/XCodec2 日文动漫域且无多 seed 与跨模型验证，AnimeScore 轴在奖励差距分析中不显著、Likability 出现机器 +0.17 与人类 HWR 36% 的脱钩，核心「预测器-人类对齐」命题在最关键轴上未获完全识别。
