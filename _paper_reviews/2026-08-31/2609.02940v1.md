## 公理审查结果

### 一、对象公理 — ✅ 8/10
- **依据**: 研究对象定义完整且边界清晰：面向 LoRA 适配、保留功能完整的 base LLM 的 warm-initialized ASR-LLM（主实验 Phi-4-Multimodal，骨干 Phi-4-Mini；验证模型 Granite-4.0-1B-Speech），提出两项对象——(1) 隐状态交互特征，逐层逐位置给出精确定义：AngleFeat = ASR-LLM 与 base LLM 隐状态的余弦相似度，MagFeat = 二者 L2 范数比（teacher forcing、音频+文本上下文 vs 纯文本）；(2) Hybrid Search 解码算法，目标 token 选择器 T(x_i) 由 YODAS 上拟合的高斯密度比 P_NE/P_nonNE ≥ τ 给出（τ=1/2 默认），贪心与 B=5 beam 交错、回滚至收敛的非目标 token，附录 A 给出伪代码。超参（B=5、α=0.2、层聚合 10-28 取 top-3 均值）、评测协议（Open ASR Leaderboard 七子集 + Common Voice、WER 与 NE-ER 双指标）逐项可核查。扣分点：τ 与高斯拟合依赖 YODAS 校准集这一隐式对象在正文中披露较简略，跨模型迁移需重校准（作者自陈）。
- **Wiki 证据**: warm-initialized ASR-LLM 谱系（Phi-4-Multimodal、SALM、Qwen3-ASR）；Open ASR Leaderboard 标准评测集；NE-ER 指标承袭命名实体错误的既有评测实践（BERT NER 标注器 dslim/bert-base-NER-uncased）。

### 二、识别公理 — ✅ 8/10
- **依据**: 问题识别有层级的量化证据链。(1) 问题存在性：warm-init 后 ASR-LLM 的命名实体错误仍显著（greedy NE-ER 26.57 vs WER 11.38），命名实体承载不成比例的上下文重要性；(2) 信号存在性：teacher-forcing 分析在 YODAS 上显示中间层（8-28）的 AngleFeat/MagFeat 对命名实体与非命名实体 token 形成可分的高斯分布，且分离度最大处出现在多 token 词的 continuation token（如 "orches" 后的 "-tras"），早期层特征近 1 无区分力、31 层效应减弱的负结果也如实报告；(3) 机制验证：α=0 消融显示去掉 LLM 融合后 NE-ER 恢复率从 96.4% 降到 68.3%，直接证明目标 token 同时受益于额外搜索与 base LLM 语义知识，即"适配后语义遗忘可由 base LLM 部分补偿"这一识别的核心机制。 Granite-4.0-1B-Speech 上分布形态复现，跨模型证据成立。
- **Wiki 证据**: ASR 与 LLM 数据规模差（Whisper ~5M 小时 vs LLM 数万亿 token）造成语义鸿沟的既有动机；LLM 适配中命名实体遗忘的先前观察；late-layer 不确定性归因于声学相近候选（附录 B.1）。

### 三、独立性公理 — ⚠️ 6/10
- **依据**: 定位有独立主张：首次（按论文自述引用范围）提出以"适配模型自身保留的 base LLM"作为推理期校正资源，将内部 warm-init 与外部校正两种整合策略统一，切入点区别于 logit-level late fusion 与 agentic 事后校正两条既有路线。但方法组件均为成熟技术的组合：余弦相似度与范数比是表征分析/探测（probing）的标准工具；rescoring、late fusion 是文中自己列出的已知基线；targeted 选择+局部 beam 扩展本质上是受限解码的常规状态机（附录 A 的伪代码无新算法结构）；τ=0 消融进一步显示"仅目标化多 token 词、不用任何隐状态特征"即可获得最高 NE-ER（23.78 优于特征选择 τ=1/2 的 24.32），削弱了核心特征模块的独立必要性——其价值收缩为 WER 稳健性（11.12 vs 11.16）。独立性主张因此打折。
- **Wiki 证据**: LLM rescoring/late fusion 校正 ASR 的既有谱系（论文 Table 中直接对比并展示其 WER 退化：rescoring 12.50、late fusion 12.79 vs beam 11.11）；hidden-state probing 的标准做法。

### 四、压缩公理 — ✅ 8/10
- **依据**: 压缩是本文最强项：训练自由、零新增参数、特征提取每位置约 10⁶ FLOPs（10·h·L，h=3072、L=33）对比一次前向的 ~10⁹，开销可忽略；hybrid 解码因仅约 10% token 触发 beam 扩展，摊销 beam 尺寸 1.4（(1−ρ)+ρB = 0.9+0.5），接近贪心成本却恢复 beam search NE-ER 增益的 96.4%（26.57→24.71，beam 为 24.71）与 WER 增益的 25%。错误校正模式（两遍）也仅需 teacher forcing，无第三模型、无外部 NER（校准后推理期不需要 BERT 标注器）。压缩-收益比在同方向工作中突出。
- **Wiki 证据**: 论文第 7 节复杂度分析（FLOPs 对比与有效 beam 公式）；无参数方法的部署优势（对比需额外模型的 agentic 校正路线）。

### 五、效用公理 — ⚠️ 5/10
- **依据**: 效用真实但幅度窄、且在主指标上未超过其要超越的基线。可确认的收益：(1) 贪心档 NE-ER 26.57→24.71（-1.86，恢复 beam 增益 96.4%，成本仅 1.4×贪心）；(2) 错误校正模式 NE-ER 18.29→17.69，TED-LIUM 相对降 12.7%、SPGISpeech 8.8%，McNemar 检验显著（NE-ER p=3.56×10⁻³⁸，WER p=9.19×10⁻⁵）；(3) 优于 rescoring/late fusion 这两个全局方法（二者 WER 12.50/12.79 全面恶化）。关键折扣一：**WER 上没有任何实质收益**——greedy+HS 11.38 与 greedy 持平，beam+HS（τ=1/2）11.12 略差于纯 beam 11.11，即论文的"自校正"在字错误率上未兑现，收益集中在 NE-ER 一个指标；折扣二：τ=0 基线（不用隐状态特征、仅目标化多 token 词）NE-ER 达 23.78，优于特征驱动选择器的 24.32，特征模块的净贡献只剩 WER 稳健性 0.04 的差距，方法核心组件的边际效用存疑；折扣三：端到端验证仅在 Phi-4-Multimodal 上完成（Granite 只做了分布层面验证），且阈值/层聚合/高斯校准依赖 YODAS，换模型需重校准，实际迁移效用未验证。
- **Wiki 证据**: 论文 Table 的 WER/NE-ER 全量对比与 τ 消融；局限性章节自陈模型依赖性与闭源系统不可用；McNemar 显著性检验。

### 六、新颖性公理 — ⚠️ 6/10
- **依据**: 核心洞察有新颖性：将适配模型与 base LLM 的隐状态交互（角度+幅度）解读为 token 语义依赖的分布信号，并用于引导解码目标化，在论文引用范围内未见完全相同的先例，层间现象学（早期无信号、中间层峰值、晚期弱化）的分析本身有独立价值；EMNLP 2026 Findings 接收提供外部评审背书。折扣：特征构造（余弦相似度、范数比）是 probing/激活分析的标准量，targeted 融合是受限解码的常规形式，τ=0 消融暗示现象的主力是"多 token 词 continuation token"这一结构性线索而非交互特征本身；外部新颖性核查不完整——Semantic Scholar 与 OpenAlex 均因 429 限流失败，引用数与同方向先前工作无法独立排除，此局限如实记录，新颖性判定以论文自述引用与 arXiv Comments 的接收记录为上限。
- **Wiki 证据**: Findings of EMNLP 2026 接收（arXiv Comments 字段）；rescoring/late fusion/agentic 校正三条既有路线（论文引言与 Table 定位）；HF Space `Splend1dchan/Listen-To-The-Latent`（可视化 demo，存在但无官方代码仓库）。

### 七、可复现公理 — ⚠️ 5/10
- **依据**: 复现有较完整路径但缺开源保障。有利面：方法细节披露充分——特征定义、层聚合（10-28 top-3）、高斯校准流程、阈值 τ∈{1, 1/2, 0}、B=5、α=0.2、回滚伪代码（附录 A）齐全；所用模型（Phi-4-Multimodal、Granite-4.0-1B-Speech、base LLM）与数据集（Open ASR Leaderboard 七子集、Common Voice、YODAS 校准集）全部公开；两个全局基线（rescoring、late fusion）实现简单。不利面：**全文无代码/模型发布链接**，arXiv 页面无代码字段，GitHub API 检索未发现官方仓库，仅有 Gradio 可视化 demo（0 likes）；高斯拟合的具体样本规模、NER 标注噪声对校准的影响、错误校正模式第二遍的完整实现细节披露有限；NE-ER 依赖特定 BERT NER 标注器，第三方复现需完全对齐标注器才能核验数字。评分取 ⚠️ 区间中部。
- **Wiki 证据**: WebFetch 全文与 arXiv abs 页面均未检索到代码链接；GitHub/HF API 核查记录（见事实锚点）。

## 总评

**优点**：
1. 分析扎实且诚实：中间层隐状态交互特征对命名实体 token 的可分性有跨模型（Phi-4-Multimodal + Granite-4.0-1B-Speech）复现，早期/晚期层的负结果如实报告，α=0 消融（NE-ER 恢复率 96.4%→68.3%）直接支撑"适配后语义遗忘可由 base LLM 部分补偿"的核心机制主张。
2. 压缩-收益比突出：训练自由、零新增参数、特征提取 FLOPs 比前向低三个数量级，摊销 beam 1.4 即恢复 beam search NE-ER 增益的 96.4%，并以实验证明全局方法（rescoring 12.50、late fusion 12.79 的 WER）确实不可用，targeted 化的必要性论证充分。
3. 评测规范：Open ASR Leaderboard 七子集 + Common Voice、WER/NE-ER 双指标、McNemar 显著性检验（p=3.56×10⁻³⁸）、τ 三档消融，错误校正模式给出分数据集相对增益（TED-LIUM 12.7%）。

**缺点**：主要问题在于收益与核心组件的验证错位——论文标题级卖点是"自校正"，但 WER 上贪心档持平（11.38→11.38）、beam 档反而略降（11.11→11.12），全部收益集中于 NE-ER 单一指标且幅度有限（beam 档 24.71→24.32）；同时 τ=0 消融显示完全不用隐状态特征、仅目标化多 token 词即可取得更好的 NE-ER（23.78），使核心特征模块的净贡献收缩为 0.04 的 WER 稳健性差距，方法的核心主张"listen to the latents"在消融面前支撑不足。次要问题：端到端验证仅在 Phi-4-Multimodal 上完成，阈值/校准的模型依赖性未解决；全文无代码发布（GitHub 无官方仓库，仅有可视化 demo），NE-ER 数字依赖特定 NER 标注器难以独立核验；Semantic Scholar 与 OpenAlex 的新颖性核查均因 429 限流失败，外部佐证不完整，此局限如实记录。

## 日报摘要

- **Strength:** 提出训练自由、零参数的 Hybrid Search：用 ASR-LLM 与 base LLM 的中间层隐状态交互（余弦相似度+范数比）定位语义依赖 token 做定向 LLM 校正，摊销 beam 1.4 恢复 beam search NE-ER 增益的 96.4%（26.57→24.71），错误校正模式 NE-ER 18.29→17.69（McNemar p=3.56×10⁻³⁸），已获 Findings of EMNLP 2026 接收。
- **Weakness:** WER 无实质收益（beam 11.11→11.12），收益集中于 NE-ER 单指标且 τ=0 消融显示不用隐状态特征仅目标化多 token 词即得更好 NE-ER（23.78 vs 24.32），核心特征模块边际贡献存疑；全文无代码开源，端到端验证仅 Phi-4-Multimodal，外部新颖性核查因 Semantic Scholar/OpenAlex 429 限流失败。
