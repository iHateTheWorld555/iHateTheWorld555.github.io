## 公理审查结果

### 一、对象公理 — ✅ 9/10
**依据**：研究对象清晰且形式化完整：单通道语音增强，在复数 STFT 域建模为映射问题——输入 2×256×256 的幅度-相位特征图（C=2, F=256, T=256），非重叠 16×16 patch 线性投影得 N=256 个 token，多层 transformer 编码后由复数 U-Net 解码器（CUNet）同时重建增强幅度与相位，训练目标为波形 L1、多分辨率 STFT（FFT 512/1024/2048）与 SI-SDR 的加权和（λ=1.0/1.0/0.05）。任务边界明确：单通道、16 kHz、SNR 0–20 dB 训练；指标体系完整（SI-SDR、PESQ wb/nb、STOI、DNSMOS 四项、MACs、RTF），并显式给出复杂度测量协议（A100-80G、ptflops、RTF 取 20 次运行平均）。唯一保留点是"phase-aware"的达成度依赖整个 CUNet 解码器而非显式相位建模模块，对象定义与这一表述之间有轻微落差。
**Wiki 证据**：方法节 token 化与 Algorithm 1、损失定义段（λ 权重逐项给出）、实验配置节（STFT 窗 400/移位 100、25,500 样本段长）、指标与复杂度测量协议段。

### 二、识别公理 — ⚠️ 6/10
**依据**：论文识别了三个真实问题：(1) CNN 只能通过堆叠卷积/池化间接捕捉长程时频依赖；(2) 既有 ViT 方案（文献[14]）重用带噪相位且缺卷积解码器，限制感知质量；(3) 一个有价值的经验发现——声学失配（混响）下所有基线的 SI-SDR 均跌破未处理输入 9.03 dB（CUNet-S 8.61、CUNet-B 8.24、MP-SENet 8.14、TF-GridNet 7.45、CleanUNet 3.57），而 U-PAST 全家族超过未处理（U-PAST-H 9.76 dB）。识别与验证的闭环不完整：混响鲁棒性为何出现，论文没有给出任何机制分析或消融（例如编码器深度在混响条件下的非单调表现 U-PAST-L 9.37 < U-PAST-B 9.72 仅陈述、未解释）；"相位建模带来质量提升"这一识别也未通过固定解码器、对比幅度-only 变体的对照实验验证。识别到的问题真实，但归因停留在经验观察层面。
**Wiki 证据**：引言的问题陈述、Table 4 混响条件全基线跌破未处理的数字链、消融/深度影响段对非单调现象的无解释陈述、Limitations 节。

### 三、独立性公理 — ⚠️ 5/10
**依据**：正项：三个公开语料（DNS Challenge 2020、VoiceBank-DEMAND、Libri2Mix min 模式 + WHAM! 噪声）、四种测试条件（匹配/声学失配/两种数据集失配）的评测矩阵在同类工作中覆盖面较广；所有模型统一重采样 16 kHz、统一 500 epochs 训练预算的表述暗示了公平比较意图。扣分项：(1) TF-GridNet 基线使用第三方 X-TF-GridNet 发布代码（论文自述"无官方实现"），CUNet 基线由文献[24]缩减为 4 层编码器——两个核心基线均为非官方/修改版实现，结果可比性存疑；(2) 全部结果无统计显著性检验、无多次运行方差；(3) 各基线是否在相同数据增广与训练超参下重训未逐项说明；(4) U-PAST-H 在匹配条件取得 PESQ-wb 3.41 而次优的 TF-GridNet 仅 2.89，0.52 dB 的差距在本领域异常大，且与 SI-SDR 排序（TF-GridNet 领先 2.44 dB）严重背离，论文未讨论该异常的可能来源（如 DNSMOS/PESQ 对相位伪影的敏感性差异），独立评测机构复核缺位。
**Wiki 证据**：Table 2 基线复杂度与实现来源说明（X-TF-GridNet、CUNet 缩减）、Table 3–6 全部主结果、复杂度测量协议段。

### 四、压缩公理 — ⚠️ 7/10
**依据**：正向：架构设计克制紧凑——隐藏维度固定 96、3 注意力头、patch 16×16，仅以层数（1/4/8/12）作为唯一设计变量系统研究复杂度-性能权衡，四个变体参数 1.17–2.40M、MACs 4.39–4.71G，随层数近线性增长，消融结论清晰（三个条件下 SI-SDR 随深度近单调提升）；token 到特征图的投影与 CUNet 解码器职责划分干净，一页可讲清。负向：(1) 三项损失 λ=1.0/1.0/0.05 为手工设定且无敏感性分析，0.05 的 SI-SDR 权重缺乏说明；(2) 复数卷积块 + CPReLU + 复数批归一化 + dropout 0.2 的解码器配置沿用文献堆叠，未论证各组件必要性；(3) 投影模块可堆叠 1–3 个的具体选择规则未给出；(4) 混响条件下的非单调深度行为（S/B/L/H = 9.66/9.72/9.37/9.76）说明该设计并非在所有条件下性质良好，压缩后的设计空间仍有未理解区域。
**Wiki 证据**：Table 1 变体配置、损失定义段、Table 2 复杂度梯度、Table 4 与消融段的非单调数字。

### 五、效用公理 — ⚠️ 6/10
**依据**：正向：解决的是真实场景痛点——小参数量（1.17–2.40M）语音增强适配资源受限端侧；混响失配下是唯一超过未处理输入的模型族（U-PAST-H SI-SDR 9.76 dB 全场最佳），对真实含混响录音的鲁棒性有实用意义；匹配条件 PESQ-wb 3.41 为全场最佳。负向：(1) 四个条件中三个 SI-SDR 落后 TF-GridNet 1.62–2.44 dB（匹配 15.69 vs 18.13；VoiceBank-DEMAND 16.72 vs 18.34；LibriMix 10.30 vs 12.03），LibriMix 上也落后 MP-SENet 0.26 dB，摘要所称"closely trails by 0.26–0.63 dB"仅覆盖部分条件，与表格全貌有出入；(2) MAC 优势（4.71G vs TF-GridNet 85.58G、MP-SENet 164.01G）未转化为延迟优势——RTF 0.0126–0.0151 慢于纯卷积的 CleanUNet（0.0058）与 CUNet（0.0081–0.0115），transformer 编码器每 MAC 硬件效率低，"性能-成本权衡"的核心卖点打了折扣；(3) 面向端侧部署的模型未报告 INT8/量化或流式推理适配，实用落地路径不完整。
**Wiki 证据**：Table 3–6 主结果、Table 2 与复杂度测量段的 MACs/RTF 对照、Limitations 节对延迟短板的自述。

### 六、新颖性公理 — ⚠️ 4/10
**依据**：论文主张"首个用于音频信号增强的混合 transformer-U-Net"且"首个在复数域这样做"。arXiv API 检索（本审稿实测）直接否证了这两个"首个"：MUSE（2024）已是 Taylor Transformer + U-Net 的轻量级语音增强；U-Former（2022）将 self/cross-attention 引入单耳增强的 U 形架构；LORT（2025）、IMSE（2025）延续同一组合方向；复数域方面 DCUC-Net（2023）将 deep complex U-Net 与 Conformer（transformer 变体）结合并处理复数谱，Deep Complex U-Net（2019）早已在复数域做相位感知重建。U-PAST 的具体新组合——AST 风格的非重叠 patch token 化复数谱 + 2D 正弦位置编码 + 层级复数 U-Net 解码器——仍有一定辨识度（相对文献[14]的 ViT-only 读出 + 带噪相位确实是补全），且混响失配下"全基线跌破未处理、本方法除外"的现象是本文独有的实验发现。但以"首个"措辞标榜的组合性创新，经先行工作核验后新颖性缩水明显，贡献应重新定位为"一个已存在架构方向上的复数域实例化 + 失配鲁棒性研究"。因 Semantic Scholar/OpenAlex 均查询失败，2024 年后是否还有更近的同型工作未能穷尽核验，此处以 arXiv API 命中为下限如实记录。
**Wiki 证据**：贡献声明中的"首个"措辞、方法节与文献[14]的对比；本审稿 arXiv API 检索命中的 MUSE/U-Former/DCUC-Net 等 11+4 篇先行工作元数据。

### 七、可复现公理 — ⚠️ 4/10
**依据**：正向：训练与评估超参数披露详尽（Adam lr 0.001、余弦调度 + 100 步 warmup、500 epochs、段长 25,500 样本、STFT 窗 400/移位 100/FFT 512、损失权重、dropout、DNS 100 小时干净语音 + SNR 0–20 dB 采样协议），全部数据集公开可下载，复杂度测量协议（GPU 型号、ptflops、20 次运行平均）可照抄。负向：(1) 论文全文未提及任何代码、模型权重或训练配置的开源发布承诺；(2) GitHub Search API 实测未找到任何 U-PAST 相关仓库（total_count=0），截至审稿日无第三方可验证实现；(3) 核心基线 TF-GridNet 依赖第三方 X-TF-GridNet 代码，他人想复现对照实验需先解决该基线自身的非官方实现问题；(4) DNS 训练集的噪声构造细节（噪声种类、加噪脚本）描述层级不够到脚本级。复现需从零重写完整训练流水线，成本较高。
**Wiki 证据**：实验配置节全部超参数、GitHub Search API 返回 total_count=0 的实测记录、论文中无任何代码链接的事实。

## 总评

**优点**：这是一篇实验覆盖面广、工程执行规范的方法型论文。其一，评测矩阵扎实：三个公开语料 × 四种条件（匹配、声学失配、两种数据集失配）统一 16 kHz、统一 500 epochs 预算，并系统给出参数/MACs/RTF 三维复杂度剖面（Table 2），同类工作中少见。其二，最有价值的发现是失配鲁棒性：混响条件下五个基线的 SI-SDR 全部跌破未处理输入 9.03 dB（TF-GridNet 7.45、CleanUNet 3.57），而 U-PAST 全家族反超（H 变体 9.76 dB 全场最佳）——这一现象若得到机制解释，对"端侧模型在真实含混响场景的可靠性"讨论有实质贡献。其三，复杂度-深度权衡研究干净：固定宽度 96、仅变层数（1/4/8/12），三个条件下 SI-SDR 近单调提升，且 MACs 仅从 4.39G 增至 4.71G，为小参数量设计提供了可复用的参照点。其四，自述局限诚实：明确承认 SI-SDR 落后 TF-GridNet 1.62–2.44 dB、MAC 优势未兑现为延迟优势（RTF 慢于 CUNet/CleanUNet）。

主要问题在于新颖性主张与证据闭环两端。新颖性上，论文以"首个混合 transformer-U-Net 音频增强""首个复数域"自居，但本审稿经 arXiv API 检索实测，MUSE（2024）、U-Former（2022）、LORT（2025）、IMSE（2025）已构成该组合方向的先行序列，复数域的 DCUC-Net（2023，complex U-Net + Conformer）与 Deep Complex U-Net（2019）更早覆盖相位感知复数重建——"首个"措辞不成立，贡献应降格为已知方向的复数域实例化。证据闭环上，混响鲁棒性这一最强卖点没有任何机制分析或消融解释（深度非单调现象 U-PAST-L 9.37 < U-PAST-B 9.72 仅陈述未解释）；"phase-aware 带来质量提升"缺幅度-only 对照；两个核心基线为非官方/修改版实现（X-TF-GridNet、4 层缩减 CUNet）；匹配条件下 U-PAST-H PESQ-wb 3.41 与次优 2.89 的异常大差距与 SI-SDR 排序背离且未讨论；全部结果无显著性检验。实用层面，MAC 优势未转化为延迟优势（RTF 0.0126–0.0151 慢于 CUNet 0.0081–0.0115），摘要"落后 0.26–0.63 dB"的表述与四条件全貌（最多落后 2.44 dB）存在选择性呈现。可复现上，论文无任何代码/权重发布，GitHub 实测无对应仓库。另如实记录：Semantic Scholar（429 限流）与 OpenAlex（预算耗尽）查询均失败，基线引用数据与 2025-2026 年最新同型工作未能经第三方索引穷尽核验。

## 日报摘要

- **Strength:** 混响失配下唯一超过未处理输入（9.03 dB）的模型族——U-PAST-H 以 2.40M 参数、4.71 GMACs 取得全场最佳 SI-SDR 9.76 dB（五个基线全部跌破未处理，TF-GridNet 仅 7.45），并在匹配条件取得全场最佳 PESQ-wb 3.41。
- **Weakness:** "首个混合 transformer-U-Net 音频增强"的"首个"主张被 arXiv 实测的 MUSE（2024）/U-Former（2022）/DCUC-Net（2023，复数域）等先行工作否证，四条件中三个 SI-SDR 落后 TF-GridNet 1.62–2.44 dB 且混响鲁棒性无机制解释；核心基线为非官方实现、无显著性检验、论文与 GitHub（实测 0 仓库）均无代码发布。
