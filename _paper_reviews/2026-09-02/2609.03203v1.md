## 公理审查结果

### 一、对象公理 ✅（8/10）
**依据**：论文把「合成前的表达规划决策」（affect、pitch、energy、rate、pause、emphasis、stance 如何被源记录许可）定义为一个独立的、可测量的评测对象——source-cited speaking plan，并给出完整的形式化：输入 x=(context text c, optional audio a, role context r, target utterance u)，系统输出带证据引用的规划 ŷ，合法性由五类确定性校验（citation legality、slot agreement、unsupported state、schema validity、one-cue counterfactual locality）判定。对象边界清晰：明确声明渲染波形质量在本次评测范围之外。「听者无关」的设计使评测可完全确定性执行，1,440 条 checked source-label cases 全部通过校验且 100% 覆盖，8,882 条 measurement entries。扣分点：评测对象依附于极窄的构造（两条 target texts、一个 scene label、24 role labels、15 emotion-intensity keys、每 key 一个 gold plan），对象的生态代表性存疑。
**Wiki 证据**：RAVDESS 1,440 条 source-label cases；CREMA-D 1,800 clips 跨语料 listener-free 检查；波形锚点验证 6/6 方向支持、最小 AUC ≈ 0.675。

### 二、识别公理 ✅（8/10）
**依据**：因果识别设计是本文最强项。(1) source-label testbed 固定文本、仅变动许可的 source label，直接隔离「交付选择由源记录许可」这一变量；(2) shortcut 对照完整：key-lookup oracle 在 seen keys 上达到 1.000 plan-slot 精度、leave-key-out 下崩至 0.242，emotion-only prior 在 source-key-disjoint split（60/16/24，零 key 重叠）上仍有 0.958 slot 精度但 counterfactual consistency 为 0.000——这些对照精确演示了 slot 精度单指标不安全；(3) one-cue counterfactual edit 只允许影响 cue-tied slots，识别出真正的证据使用；(4) 双重 disjoint（source-key 与 source-emotion：'angry'/'calm' test-only、'fearful' dev-only，emotion prior 降至 0.219 slot）从两个轴切割泛化。7B locality SFT+CF 修复将 plan-slot/locality 从 0.684/0.141 提升到 0.919/1.000，修复增量可归因。扣分：label 来自确定性重构（key→gold plan 一一映射），gold 本身未经独立人工标注（Jaccard/kappa 仅适用于未来新增标注）。
**Wiki 证据**：Table 1（32 seeds，7B holdout 0.684±0.041 plan / 0.141±0.104 cf. vs 修复后 0.919±0.041 / 1.000±0.000）；Table 5 source-emotion-disjoint；Table 25 oracle/majority 基线。

### 三、独立性公理 ✅（8/10）
**依据**：评测独立于捷径的验证机制系统化：citation-intervention 压力测试显示丢弃全部引用保持 plan accuracy 1.000 但 semantic/legal F1 归零、伪造同 key ID 的 illegal rate 1.000——证明 citation 检查确实拦截「答案对但证据假」；primary endpoint 采用 citation-required grounded score（0.45·F1_E + 0.45·Acc_Y + 0.10·(1−Halluc)，再乘 cited-cue recall），强制证据链而非只看结果；transcript-only 对照（plan 0.277 vs 0.876）证明源通道信息不可由文本替代；retrieval 基线 grounded 仅 0.0562–0.2958，18 案全数未过阈值。PromptClean 结构化压力测试 960 outputs 100% schema-clean，量化解析噪声贡献。诚实地报告了 text-evidence control（0.1798）反超 evidence-grounded（0.1748）的校准结果，未掩盖不利数据。扣分：construct limits 明示零公开 context-audio records，多模态独立性未验证。
**Wiki 证据**：Table 10 citation-intervention；Table 12 源通道消融 +0.488 citation-required [0.483, 0.492]、+0.599 plan [0.589, 0.610]；Tables 26–27 retrieval 基线。

### 四、压缩公理 ✅（8/10）
**依据**：指标体系压缩为单一 primary scalar（citation-required grounded score）并论证了为何它优于 plan-slot accuracy；训练目标 L(θ)=L_sft − λ_E·R_E − λ_Y·R_Y − λ_C·R_C 用三个奖励项紧凑编码 evidence precision/recall、slot agreement、局部反事实一致性；确定性校验器替代听者评分，将需要人工/神经裁判的开放评测压缩为可机器执行的规则集。bootstrap 108-case 校准 split（324 gold cues、0 validation errors）单独隔离标定环节。论文明确区分「typed citation 是审计接口」与「提示配方」两个层面的结论，未过度外推。扣分：指标命名繁多（grounded、citation-required grounded、evidence F1、hallucinated-evidence rate、cf. consistency 等），阅读负担偏高。
**Wiki 证据**：Table 24 bootstrap 校准；PromptClean Δ +0.0105 CI [0.0090, 0.0120]。

### 五、效用公理 ⚠️（5/10）
**依据**：实际效用受构造限制严格束缚，论文自己在 Limitations 中承认：两条 target texts、一个 scene label、零公开 context-audio records、确定性 key→plan 映射，controlled split 无法确立跨 scene/role/自然对话的泛化。waveform 渲染质量明确排除在评测外，对 TTS 落地的端到端价值需后续工作衔接；无人工听感研究（作者说明需要独立治理与预注册）。跨语料 CREMA-D 检查（1,800 clips）和 100-case full100 协议提供了部分跨数据面效用，但 dominant residual failures 集中在 rate- 和 stance-slot 不匹配（disgust Δ CR +0.439、surprised +0.496 为最难切片），说明现有模型离可用尚远。作为社区评测资产有价值，作为当下可直接指导 expressive TTS 部署的工具效用有限。
**Wiki 证据**：Limitations 章节；Table 7 weakest keys（fearful:normal 7B plan acc. 仅 0.269）；Table 13 hardest slices。

### 六、新颖性公理 ⚠️（7/10）
**依据**：核心新颖点确凿：将「源记录是否许可交付决策」作为合成前的 listener-free 评测任务，并用确定性引用校验器落地，相关工作章节系统梳理了 context-aware TTS（ActorMind、CoT-TTS Challenge、Spark-TTS）、speech-reasoning 基准（Listen First Then Answer、Hear2Act、EmotionThinker、MMAR、ARC）、audio 生成推理（ThinkSound、PrismAudio、AudioX、Audio Flamingo Next、LLaSE-G1）与 process-reward modeling（DC-W2S、Omni-Reward），并论证无一暴露「哪条记录许可了哪个交付字段、该记录是否真被使用」。shortcut falsification + citation-required endpoint 的评测方法论组合有独立贡献。「源通道比参数规模更重要」（+0.488/+0.599 vs 3B→7B 的 +0.023/+0.051）是一个可引用的量化结论。扣分：评分器思想（citation/legal check）承接 process-reward 与 attribution eval 的既有范式，属组合式创新；且因 Semantic Scholar 限流未能独立交叉核实相关工作覆盖，新颖性声明依赖作者自述。
**Wiki 证据**：Related Work 章节列举；OpenAlex cited_by_count=0（发布 3 天，尚无引用可佐证影响）。

### 七、可复现公理 ⚠️（7/10）
**依据**：开源信号经 GitHub API 实测确认：仓库公开且活跃（2026-08-27 至 09-02 连续提交，最近提交为「Strengthen public reproducibility README」），含 src/schemas/tests/BENCHMARK.md/pyproject.toml，声明发布 manuscript source、derived split、planner schema、verifier/evaluation code、table-regeneration commands。评测全确定性（无神经裁判），32 seeds 报告均值±标准差并给 CI，复现门槛低。扣分：raw audio 因许可原因排除（复现者需自备 RAVDESS/CREMA-D 并重建派生数据，映射代码是否完整覆盖未验证）；private checkpoints 与 launch logs 不公开，Table 11 的 3B/7B 学习结果无法直接加载复现；单人作者、1 star/0 forks 的社区检验近乎为零；仓库许可证为 NOASSERTION（非标准 SPDX），法律上复用边界不清。
**Wiki 证据**：GitHub API 仓库元数据与提交历史；论文 Reproducibility 段自述排除项。

## 总评

**优点**：(1) 评测对象的定义干净且可机器执行——把「交付选择是否被源记录许可」变成确定性校验任务，五类校验器完整覆盖引用合法性、slot 一致、无虚构状态、局部反事实响应；(2) shortcut falsification 设计教科书级——lookup oracle、emotion prior、transcript-only、retrieval 四类对照精确划定 slot 精度指标失效的边界（oracle 1.000→0.242、prior 0.958/0.000 cf.），并诚实报告 text-evidence control 反超的不利校准数据；(3) 主结论量化扎实且有统计纪律：32 seeds、CI、双重 disjoint 切割，源通道效应（+0.488 citation-required）远超规模效应（+0.023），7B locality SFT+CF 修复 0.684/0.141→0.919/1.000；(4) Limitations 写得坦诚，构造边界与适用范围逐条自曝。

**主要问题在于效用天花板过低**：整个评测构造只有两条 target texts、一个 scene label、零公开 context-audio records、确定性 key→plan 一一映射，gold 规划未经独立人工标注，controlled split 无法支撑跨场景、跨角色、自然对话的泛化声明；渲染波形质量与人工听感被排除，距离 expressive TTS 的真实评估链路还差一整段；3B/7B checkpoints 与 raw audio 不随仓库发布，学习型结果的可复现性依赖第三方重建数据管道；相关工作的新颖性声明未能经独立文献索引交叉核实（Semantic Scholar 限流），且评测器思想承接 process-reward/attribution eval 范式，属组合式贡献。

## 日报摘要

- **Strength:** 把合成前交付规划的源引用合法性变成确定性可校验任务，shortcut 对照证明 slot 精度不安全（oracle 1.000→0.242），7B locality SFT+CF 修复将 plan-slot/局部性从 0.684/0.141 提到 0.919/1.000，源通道效应（+0.488）远超规模效应（+0.023）。
- **Weakness:** 评测构造过窄（2 条 target texts、1 个 scene、零公开 context-audio、确定性 key→plan 映射、无独立人工标注），波形质量与人工听感被排除，checkpoints 与 raw audio 不公开，无端到端效用证据。
