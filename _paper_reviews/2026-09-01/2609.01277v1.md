## 公理审查结果

### 一 对象公理
- 判定：✅
- 分数：8
- 依据：研究对象真实、定义清晰、操作化完整。任务被形式化为构建免训练调度算子 S(𝒢_θ, c, {𝒯^u})：给定含 N 句引述话语的提示 c 与用户指定的起止区间，在不微调冻结骨干 𝒢_θ 的前提下把耦合的语音与视觉口型放置到指定区间。claim 外延与实验范围一致：实验明确限定在 5 秒音视频片段、两个骨干（LTX-2 与 daVinci-MagiHuman）、FP8 量化蒸馏 + 8 步采样配置，未越界宣称对长视频、其他架构或微调场景有效。基准 SpeechShift 的四种说话结构（SS–SU / SS–MU / MS–SU / MS–MU 各 100 条）覆盖了任务的合理变体空间。
- Wiki 证据：arXiv abs 页确认单一 v1 提交、无 venue；HTML 正文的任务形式化与实验配置逐项对应，未见对象漂移。相关任务查重受索引限流影响未完成，"首个区间级语音调度任务"的表述依据论文自身声明与 FreeAudio（T2A 单模态时序规划先例）的对比，已如实记录不确定性。

### 二 识别公理
- 判定：⚠️
- 分数：6
- 依据：机制归因有两条证据链且各有消融支撑。(1) "时序敏感交叉注意力头暴露源区间"：Fig. 3 消融显示 Attn@x̂₀ⁿ（回放干净潜变量后取注意力）在 IoU 与起止误差上同时优于 Attn@xₙ、Decode@x̂₀ⁿ、Decode@xₙ 三种替代定位方式，且给出机制解释——中间去噪步的波形中语音活动尚未稳定成形，解码定位不可靠；(2) "x̂₀ⁿ 空间重映射有效"：Fig. 4 显示 Remap@x̂₀ⁿ 的 HR₀.₂ 与 WER 均优于 Remap@vₙ、Remap@xₙ、Post-hoc，直接重映射速度或噪声潜变量会破坏去噪轨迹产生不完整话语，事后重映射因无后续去噪步巩固而失效；(3) Table 2 显示区域感知读映射（HR₀.₂ 69.8%，Span Win 67.9%）大幅优于 piecewise-linear（48.6%/12.7%）与 global PCHIP（52.3%/19.4%），且仿射解的 κ_u 有"局部语速比"的物理解释，非语音段三次桥接有最小曲率的变分依据。识别链条的缺口：(a) "时序敏感"的注意力头 h* 与层 l* 如何被筛选，正文可见部分只说"timing-sensitive"，未给筛选准则、候选头数量与该选择跨场景的稳定性证据——若头选择对骨干或场景敏感，方法的核心前提就退化为逐骨干调参；(b) 相对阈值 τ 的取值未在正文披露，也无 τ 敏感性扫描；(c) 源区间定位精度本身没有独立报告（Fig. 3 报的是端到端 IoU/误差），定位误差与重映射误差的贡献无法分离；(d) 主表单种子（seed 42），跨种子鲁棒性放在被截断的附录，正文结论的方差未知。
- Wiki 证据：HTML 正文三个消融（Fig. 3 / Fig. 4 / Table 2）数字齐全且方向一致，构成内部证据链；头筛选准则与 τ 取值的缺失为正文事实（非截断推测，正文可读部分无此内容）；附录未读取，若筛选准则在附录则此缺口减轻但审稿时不可确认。

### 三 独立性公理
- 判定：⚠️
- 分数：6
- 依据：评测协议大体独立、基线选取合理。指标为社区标准工具：WER（语音可懂度）、PQ（音频自然度）、MUSIQ（视觉质量）、LSE-C（区间内音视频同步），区间可控性指标（mE_s / mE_e / IoU / HR_δ）定义清楚。基线覆盖了免训练控制的四个合理代表：Uncontrolled、Textual Timing（提示内时间指令）、FreeAudio（真实存在的 arXiv:2507.08557，注意力约束 DAAC）、Prompt Relay（距离衰减注意力惩罚），并诚实地展示了基线在两个骨干上的分化——FreeAudio 在 LTX-2 上可用（HR₀.₂ 0.19）而在 daVinci 上近乎崩溃（0.01，WER 0.95），报告未遮掩。削弱独立性的因素：(1) 基准为自建且 400 条提示的生成方式（人工撰写或 LLM 生成）、说话人/场景来源在正文可见部分未说明，数据分布的代表性无法独立评估；(2) WER 的 ASR 模型、PQ 的具体度量（PESQ/pipe 类？）未在可见正文指明；(3) 所有基线均为作者适配的免训练方法，与需要微调的时序控制方法（若存在）无对比，"免训练基线最强"的结论缺少微调上限参照；(4) 每方法单种子，统计显著性检验缺失。
- Wiki 证据：SpeechShift 规模声明（400/102/600）来自正文，但基准未开源（GitHub 检索无果），数据构成无法独立复检；FreeAudio 的存在性经 arXiv API 独立验证。

### 四 压缩公理
- 判定：⚠️
- 分数：6
- 依据：免训练、零新增参数是硬承诺且兑现：不微调骨干、不加外挂可学习模块，调度以算子形式作用于每步去噪的 x̂₀ⁿ。变分推导本身是良好的压缩：语音段最小化 ∫(h′−1)²dt 经 Euler–Lagrange 收敛为单参数仿射映射（斜率即语速比），非语音段最小化 ∫(h″)²dt 收敛为系数由四边界条件唯一确定的三次多项式——两段闭式解使方法几乎无超参数负担。扣分点实打实：(1) 每个去噪步需把 x̂₀ⁿ 回放到冻结 DiT 提取交叉注意力，等价于每步多一次完整前向，论文仅以 "modest latency overhead" 一笔带过，未给任何延迟数字——在 8 步蒸馏采样器下约等于推理成本翻倍量级，这一开销对"推理时方法"的实用定位至关重要却未被量化；(2) 回放用的 DiT 前向与采样主前向是否共享计算（KV 缓存复用等）未说明。
- Wiki 证据：正文实验配置确认免训练（所有方法含基线均标注 training-free）；延迟开销无数字为正文事实；算法伪代码在附录（未读取）。

### 五 效用公理
- 判定：⚠️
- 分数：7
- 依据：核心效用有强量化证据且跨骨干复现。区间可控性上，LTX-2 骨干 HR₀.₂ 从 0.21（Uncontrolled）升至 0.73、IoU 0.63→0.87、起止误差 0.56/0.54s 降至 0.11/0.15s；daVinci 骨干 HR₀.₂ 0.09→0.53、IoU 0.63→0.79——增益幅度是全部基线中最强的 Prompt Relay（HR₀.₂ 0.31/0.21）的 2 倍以上，且在两种不同跨模态架构上方向一致，排除了单一骨干特解的解释。质量保持上，TimeSteer 的 WER 0.07/0.08 与 Uncontrolled 的 0.05/0.06 接近，远好于 FreeAudio（0.35/0.95），LSE-C 与 Uncontrolled 基本持平（3.10 vs 3.13；3.56 vs 3.67）——"可控性大幅提升而质量不塌"的组合成立。效用边界：(1) 实验限于 5 秒片段，长视频/多话语连续调度（话语间隔本身也是调度对象的真实场景）完全未测，而 SpeechShift 的 MS–MU 结构恰暗示此类需求；(2) 用户需为每句话提供起止区间，无自动排程（如从剧本/字幕推断时间轴）的便利层，600 话语级标注的使用成本未讨论；(3) 每步回放引入的额外延迟未量化，实际部署的吞吐代价未知；(4) 附录与跨种子分析未读取，结论稳健性只能以单种子正文数字为准。
- Wiki 证据：Table 1 两骨干全指标数字来自正文；基准未开源使第三方复算暂不可能；GitHub 检索确认无代码可查，社区信号为零（发布 4 天）。

### 六 新颖性公理
- 判定：⚠️
- 分数：6
- 依据：有真实新意但存在直接的相邻先例。(1) 任务层面：把"联合音视频生成中的话语级时间调度"独立成任务并配套首个区间级基准 SpeechShift，问题表述有原创性——FreeAudio（arXiv:2507.08557，2025-07）已在 T2A 单模态做训练-free 时序规划，本文将"何时说"扩展到音视频耦合（语音与口型同步迁移）是实质性跨越，但"训练-free 时间控制靠注意力"的核心思路承袭 FreeAudio 脉络，相关工作章节是否充分引用未在可见正文确认；(2) 机制层面：x̂₀ⁿ 空间的区域感知潜重映射（语音段仿射最优 + 非语音段三次曲率桥接）是新的技术组合，"同读映射同时作用于音视频潜变量以保持模态耦合"的设计点干净利落；Attn@x̂₀ⁿ 的定位方式与 Fig. 3/4 的空间选择消融有方法学价值。风险提示：Semantic Scholar 与 OpenAlex 的相关工作检索均 429 失败，"inference-time speech scheduling""latent remapping temporal control"方向未能完成系统查重；视频生成领域的 temporal editing / motion control 免训练方法（如 attention 时空操纵类工作）数量众多，本文与其差异未被独立核实。评分含此不确定性。
- Wiki 证据：FreeAudio 的先例地位经 arXiv API 独立确认；OpenAlex/Semantic Scholar 检索失败已如实记录于事实锚点；citationCount=0（发布 4 天，无社区验证）。

- 分数：4

## 总评

优点：(1) 任务定位准且形式化干净——把联合音视频扩散模型的"话语何时出现"独立成免训练调度任务，调度算子 S 作用于 x̂₀ⁿ 的介入点选择有 Fig. 4 消融背书（重映射 vₙ 或 xₙ 均破坏轨迹，事后重映射无去噪步巩固）；(2) 变分推导优雅且实用——语音段 Euler–Lagrange 解出单参数仿射映射（斜率即语速比），非语音段三次桥接由边界条件唯一确定，几乎零超参数负担，且同一读映射作用于音视频双潜变量天然保持模态耦合；(3) 效果幅度大且跨骨干稳健——LTX-2 上 HR₀.₂ 0.21→0.73、IoU 0.63→0.87，daVinci 上 0.09→0.53、0.63→0.79，同时 WER（0.07/0.08）与 LSE-C 与无干预采样基本持平，可控性与质量的权衡处理得当；(4) 消融设计完整——定位方式、重映射空间、读映射设计三个正交维度各有对照，FreeAudio 基线在 daVinci 上崩溃（HR₀.₂ 0.01、WER 0.95）的负结果如实报告。

主要问题在于可复现交付与关键机制细节的缺失叠加：论文的核心贡献包含"首个基准 SpeechShift"，但基准与代码均未开源（GitHub 检索无果、abs 页无链接），τ 阈值、时序敏感注意力头的筛选准则、WER/PQ 评测模型等复现必需的细节在可见正文缺失，主表又是单种子（跨种子分析在被截断的附录），导致 Table 1 的全部数字现阶段不可独立验证。其次：每步回放 x̂₀ⁿ 至冻结 DiT 的延迟开销仅以"modest"一词带过而无数字，对推理时方法的实用定位是实质性遗漏；实验限于 5 秒片段与 8 步蒸馏采样器，多话语长视频调度未测；基准数据的生成方式与说话人来源未说明，自建基准的分布代表性无从评估；外部学术索引（OpenAlex/Semantic Scholar 检索）双双限流失败，"首个区间级语音调度"声明未能完成系统查重，而 FreeAudio（2507.08557）已确立单模态 T2A 的训练-free 时序规划先例，本文与该脉络及视频领域大量免训练时序操纵工作的差异需靠论文自身叙述背书。

## 日报摘要

- **Strength:** 免训练源区间定位 + 区域感知潜重映射使 LTX-2 骨干 HR₀.₂ 从 0.21 升至 0.73、IoU 从 0.63 升至 0.87（daVinci 骨干 0.09→0.53），起止误差降至 0.11/0.15s，且 WER 与音视频同步 LSE-C 与无干预采样基本持平。
- **Weakness:** 论文核心贡献之一的 SpeechShift 基准与代码截至发布 4 天未开源（GitHub 检索无果），定位阈值 τ 与时序敏感注意力头的筛选准则缺失、主表单种子，全部主结果暂不可独立验证，每步 DiT 回放的延迟开销无量化数字。
