# Paper Review: No Detectable Change in Side-Level WER from Prompt-Level Context: A Preregistered Ablation on a Production Oral-History Corpus

## 论文类型: 评测型

这是一篇预注册的零结果评测论文（Theodore O. Cochran / AI for Altruism、Stephanie Dodson、Keith Nore，2026-08-28 提交，31 页 1 图，cs.CL 主分类）。核心问题：在推理时向多模态 ASR 大模型注入提示级上下文这一廉价领域适配手段，在真实生产环境中是否有效。作者在其自有的生产环境口述历史转录工具 Dialog Scribe 上做了完全交叉的 within-item 配对消融（3 个提示条件 × 2 个商业配置，gpt-4o-transcribe 与 gemini-2.5-flash），对 19 个磁带面（约 10.6 小时 1970–80 年代劣化磁带音频）重跑生产代码路径并对照操作员校正的逐字参考。四项预注册假设全部未被支持：gpt-4o 上 full−none 的中位配对差仅 +0.6 WER 点（区间 [−1.1, +1.0]，p=0.57），Gemini 估计过于不稳定无法支持对称的否定推断。论文未提出新模型、新数据集或新算法，贡献在于零结果本身、一个可审计的评估工作流程，以及一组构念效度分析。

## 公理审查结果

### 一、对象公理（权重 1.0）
**判定: ✅ 8/10**
- 依据: 研究对象真实且界定精准。此前在较小模型上的工作（含作者自引的 Cochran 2024 空管音频研究，提示使 Whisper WER 约减半）报告了大幅提示增益，而该机制实际部署在生产工具的提示条件层；论文正是检验该机制"在它实际发货的地方"的效果。对象操作化清晰：19 个磁带面（70 个音频 part、约 10.6 小时）、3 个提示条件（none / structure 417 字符 / full 912–1245 字符含 34 条本地词汇表）、2 个商业配置、420 条 part 级记录对应 1,290 次物理 API 调用，批次于 2026-07-11 在 3.5 小时内跑完。参考为操作员手工校正的逐字参考（参考与机器草稿 WER 差 15–50%，属高难度劣化音频域）。
- Wiki 证据: 全文 HTML 已读。OpenAlex W7204878774 确认收录；arXiv abs 页确认 OSF 预注册 DOI 与 31 页体量。数据为单一操作员的私有 Skagway, Alaska 口述历史收藏（生产库 251 项目、约 40 小时音频），真实性无疑，但私有性限制了对象的公共锚定。

### 二、识别公理（权重 1.5）
**判定: ⚠️ 6/10**
- 依据: 设计规范性与识别力的落差是本文最微妙之处。规范性极强：within-item 配对设计、OSF 预注册（假设/指标/排除规则/分析代码在确认批次评分前以 SHA-256 哈希冻结）、Wilcoxon 符号秩 + Holm 校正 + 10,000 次重采样 bootstrap 区间、事后实现审计（字节级一致提示构造、日志 420/420 提示长度匹配、全上下文输出中出现仅上下文才有的词如 "hostler"，证明操纵真实生效）。但识别力不足：(1) 每格仅单次转录，事后端点重跑（7 个面、每格 5 次，20 对配对 ΔWER 中位 +0.2，IQR [−1.9, +2.7]，范围 [−10.2, +25.0]）显示管道运行间变异**大于**确认性差异，作者自己承认该量级效应无法从单次转录中解析；(2) 固定臂顺序未随机化；(3) 主跑与重跑间隔 7 天，混淆时间与抽样；(4) 金标准参考由操作员从 full 条件机器草稿校正而来，且词表与参考出自同一人，存在锚定耦合；(5) Gemini 侧估计过不稳定，其零结果只能解读为"无证据"而非"无效应的证据"。优点是上述全部威胁均由作者主动披露且量化，无掩饰。
- Wiki 证据: 全文 HTML 已读。预注册哈希冻结、实现审计与重跑数字均在正文明确陈述；OSF DOI 经 arXiv abs 页交叉确认。

### 三、独立性公理（权重 1.0）
**判定: ⚠️ 5/10**
- 依据: 证据来源的独立性有限。配置维度有两个独立商业系统（gpt-4o-transcribe 与 gemini-2.5-flash，完全交叉），且两者结论方向一致（H1 均不显著），这是独立性的主要支撑。但数据维度高度集中：单一语料库、单一领域（1970–80 年代劣化磁带口述历史）、单一操作员、19 个面聚类于 8 位受访者（其中**一个家庭占 9/19**），有效样本量显著低于名义 n=19；结论的外推域实际上非常窄。单一机构/作者团队，无独立复现；Gemini 侧的不稳定性进一步削弱了跨配置独立性推断的对称性（两侧零结果的可信度不同）。
- Wiki 证据: 全文 HTML 已读，聚类结构与排除规则在方法章节明确陈述。OpenAlex 无第三方引用记录；Semantic Scholar 查询失败（如上），第二索引核验缺失。

### 四、压缩公理（权重 1.0）
**判定: ✅ 8/10**
- 依据: 论文将一个容易膨胀的问题压缩为四个预注册假设与一个主评估量（side-level WER 的配对差），全部头条结果各一句话可压缩：H1 gpt-4o +0.6 [−1.1,+1.0]、Gemini −0.4 [−2.5,+7.0]；H2 实体召回 −0.3/−1.7；H3 full−structure +0.1/+0.4；H4 过偏置 0/+1 token，Holm 校正后全不显著。探索性分析（配置差距、循环病态、词汇覆盖、序列对齐指标）均明确标注为事后且与确认性结果分离，符合预注册卫生学。构念效度分析也做了量化压缩：列表 token 错误 23.7%→22.0%（−1.7 点，跨构造变体 −1.5 至 −2.4 稳健），但列表短语仅占约 4.6% 参考词元，折合约 0.08 个 WER 点——一个干净的数量级论证，解释了"真实效应被 WER 稀释"。
- Wiki 证据: 全文 HTML 已读。四假设清单与 0.08 WER 点的稀释论证均为正文原数字；未发现为凑指标堆砌的冗余组件。

### 五、效用公理（权重 2.0）
**判定: ⚠️ 6/10**
- 依据: 对特定实践者（劣化历史音频转录工具的操作与维护者）效用直接且可操作：(1) 探索性发现配置选择的杠杆远大于提示工程——gpt-4o-transcribe 比 gemini-2.5-flash 中位好 **17.8 WER 点**（p<0.0001，分层后 18.8/12.8）；(2) 输出筛查的必要性被量化——Gemini 无提示条件下 5/19 面出现病理性输出（WER>100%），检查的 12 个病态单元格中 8 个存在逐字循环（重复 46–3,924 次/格），全部为 Gemini；(3) 主张序列对齐的 token 级指标（列表词错误、归因准确率）作为一等公民，与 ContextASR-Bench、IndicContextEval 等上下文 ASR 评测社区的关切呼应。但效用边界明显：零结果外推力受限于私有小语料（有效 n<19）、未预注册等价边际（不能宣称"等效"）、Gemini 侧重跑区间 [−25.5, +14.6] 基本无信息量；对更广泛的 ASR 社区，本文更多是方法学示范而非可直接迁移的结论。评估工作流程（冻结预注册+事后审计+效度威胁分析）可复制，但尚无第三方采用证据。
- Wiki 证据: 全文 HTML 已读。GitHub API 检索确认无官方仓库与下游工具；OpenAlex 无引用记录（发布一周，如实记录为"暂无采用证据"）。

### 六、新颖性公理（权重 2.0）
**判定: ⚠️ 7/10**
- 依据: 新颖性在认识论层面而非技术层面。ASR 文献中预注册零结果极为罕见（发布偏倚下负面结果通常不发表），"在机制实际部署的生产路径上做实现审计过的配对消融"的问题设置是新的；构念效度论证（WER 作为聚合指标系统性稀释/discard 上下文的真实效应，0.08 WER 点 vs −1.7 列表 token 错误点的对照）具有超越本文语料的方法学价值。OpenAlex 标题精确检索仅命中本文。但方法组件均为成熟工具：配对消融、Wilcoxon/bootstrap/Holm、序列对齐（Levenshtein 类）都是标准做法；与解码时上下文偏置文献（shallow fusion、CLAS、trie 深度偏置）及上下文评测基准（ProfASR-Bench、ContextASR-Bench、IndicContextEval）的对照停留在引用层面，未做系统定位；作者自引的 Cochran 2024 是同一团队的先行工作，本文可视为其"负向复制+升级设计"。综合：问题设置新、方法旧、与相关评测文献的差异化论证偏薄。
- Wiki 证据: 全文 HTML 已读，相关工作清单如上。OpenAlex 精确标题检索 count=1；Semantic Scholar 第二索引核验失败（如实记录）。

### 七、可复现公理（权重 1.0）
**判定: ⚠️ 5/10**
- 依据: 复现基础设施一半到位一半缺失。到位项：OSF 预注册（DOI 10.17605/OSF.IO/NS49B）含假设、排除规则与哈希冻结的分析代码；OSF 材料组件（osf.io/9nsvr）含发布材料与带日期的 provider 文档快照（针对商业 API 版本漂移这一真实威胁做了防御）；论文含 31 页方法细节与审计日志描述。缺失项：音频与参考转录为私有口述历史材料（含可识别个人信息，无法公开——这是语料性质决定的结构性限制）；无 GitHub 官方代码仓库（GitHub API 检索 total_count=0）；依赖闭源商业 API（gpt-4o-transcribe / gemini-2.5-flash），即使流程文档完备，第三方复现仍受 API 版本漂移与私有音频双重制约，重跑变异（单格 WER 从 39% 到 525%）本身就说明精确复现几乎不可能。

## 总评

优点：这是一篇方法学卫生学近乎教科书级的零结果评测。预注册在确认批次评分前以 SHA-256 哈希冻结全部假设与分析代码，事后实现审计用字节级日志（420/420 提示长度匹配）与词汇出现证据证明操纵真实送达模型，排除 2 个试点面（n=17）后结果不变，重跑变异的干扰被作者主动量化而非掩盖。构念效度分析是全文最有洞察力的部分：full 条件下列表短语覆盖 +7.8（gpt-4o）至 +14.6（Gemini）个百分点、列表 token 错误下降 1.7 点且跨变体稳健，但只折合约 0.08 个 WER 点——它精确解释了为什么聚合 WER 看不到上下文效应，并为上下文 ASR 评测给出了序列对齐 token 级指标的方向。实践层面，配置差距（中位 17.8 WER 点）与 Gemini 病理性循环输出（8/12 病态单元格、单格重复最高 3,924 次）的量化，对部署团队是直接可用的操作提醒。

主要问题在于识别力与外推域的先天不足：确认性结论建立在 19 个面（有效 n 更低，8 位受访者中一个家庭占 9 个面）的单次转录上，而事后重跑显示管道运行间变异（配对 ΔWER 范围 [−10.2, +25.0]）大于被检验的效应量级，作者据此只能支持"无可检测变化"，无法支持更希望的等价性结论；Gemini 侧估计过不稳定，使其零结果与 gpt-4o 侧不对称（一侧是较可信的零、一侧近乎无信息）。参考锚定（金标准由操作员从 full 条件草稿校正、词表与参考同人）与固定臂顺序、7 天重跑间隔是作者已披露但客观存在的效度威胁。数据为私有语料且无公开代码仓库，第三方复现受私有音频与商业 API 漂移双重限制。事实锚点核查记录：arXiv abs 页与 OpenAlex（W7204878774）确认元数据；Semantic Scholar API 查询无可解析返回（第二索引引用数据缺失，如实记录）；GitHub API 两次检索均 0 结果，确认无官方仓库。

## 日报摘要

- **Strength:** 预注册+哈希冻结+实现审计的零结果评测：19 面/10.6 小时劣化磁带上 full 提示对 gpt-4o-transcribe 的 side-level WER 配对差仅 +0.6 点（[-1.1,+1.0]，p=0.57），四项预注册假设全不显著，并量化出配置选择杠杆（gpt-4o 比 gemini-2.5-flash 好 17.8 WER 点，p<0.0001）与列表 token 错误 −1.7 点但仅折合 0.08 WER 点的构念稀释。
- **Weakness:** 每格单次转录的重跑变异（配对 ΔWER 范围 [-10.2,+25.0]）大于被检验效应量，19 面聚类于 8 位受访者（一个家庭占 9 面）致有效 n 更低，Gemini 侧重跑区间 [-25.5,+14.6] 无信息量，私有语料+无 GitHub 代码仓库+商业 API 漂移使第三方复现近乎不可行。
