# Paper Review: HEAR: Real Voices, Real Bias: A Large-Scale Human-Recorded, Demographically Diverse Benchmark for Audio Language Models

## 论文类型: 数据集型

HEAR 是 Meta Superintelligence Labs 的一份 4 页短文，发布了一个全部由真人录制的语音偏见评测集：$843$ 名美国参与者用手机在家录了约 $87$k 条音频，分 Spoken BBQ（把文本 BBQ 改成第一人称后朗读）和 Open QA（$50$ 个开放式日常请求）两部分。

论文另提出 SIR、FR、VCD、DMD、DDR 五个指标，在 GPT Realtime、Gemini Realtime、Qwen3-Omni-30B-A3B、Gemma4-E4B 四个模型上跑了一遍，并比较了「默认」与「要求分析说话人人口属性」两种 system prompt。

核心贡献落在数据本身。数据已在 GitHub Release 放出（CC BY-NC 4.0）。

## 实验结果审查

### 结果到底怎么样

评测型论文没有「提出的方法」，这一条改问：论文的几条主结论，在它自己的表上站不站得住？

逐条对表的结果是：多数定性结论在 Table 1 和 Table 3 上至少有一处被自身数字反驳。

**结论一：「所有模型对男性比对女性更稳定、对年轻人比对老年人更稳定」（§4.2）。**

性别一列成立：Table 1 默认 prompt 下 VCD(Female,Male) 为 GPT $18.42\%$、Gemini $12.57\%$、Qwen $26.34\%$、Gemma $23.80\%$，同号且量级大。

年龄一列不成立。VCD(Old,Young) 默认 prompt 下 Qwen 为 $-7.43\%$，按式 3 的定义，负值表示老年组翻转更少；personalized 下 Gemini $-3.15\%$、Qwen $-3.98\%$、Gemma $-20.62\%$。$8$ 个格子里 $4$ 个是负号，「所有模型」的说法与表不符。

**结论二：「Gemini Realtime 在所有轴上 VCD 绝对值最低，Qwen-Omni 一致最高」（§4.2）。**

语言轴上 Gemini 默认 VCD(Non-EN,EN) 为 $11.31\%$，是四个模型里最高的（GPT $5.39\%$、Gemma $7.00\%$、Qwen $9.37\%$）。年龄轴上 Qwen 的 $|-7.43\%|$ 低于 GPT 的 $15.66\%$ 和 Gemma 的 $16.03\%$。两条「consistently」都被反驳。

**结论三：「personalization 指令一致地放大人口差异」（摘要、§4.3）。**

这是摘要里的头部结论。

在 Table 1 上逐格比较 $|$默认$|$ 与 $|$personalized$|$：GPT 和 Gemini 的 $5$ 个指标全部变大；Qwen 只有 $2/5$ 变大（VCD(F,M) $26.34\%\to22.82\%$，VCD(Non-EN,EN) $9.37\%\to-6.28\%$）；Gemma $3/5$ 变大。合计 $15/20$，并且 Qwen 和 Gemma 的性别 VCD 都在变小。

在 Table 3 的 Open QA 上方向直接相反：personalized 让 GPT 的 Disparity 从 $8\%$ 降到 $6\%$，Gemini 从 $18\%$ 降到 $6\%$，Gemma 从 $10\%$ 降到 $8\%$，只有 Qwen 从 $22\%$ 升到 $54\%$。论文正文 §5 自己也写了「do not increase the disparity for most of the models except for Qwen-Omni」，摘要里却写成「consistently exacerbate」。

因此在论文的两个任务上，「personalization 放大偏见」只在 MCQA 的部分格子里成立，在开放式任务上 $4$ 个模型里 $3$ 个是反例。

**结论四：「SIR 在非负向问题上更高，说明模型 sycophantic」（Table 2）。**

数字方向成立：SIR 负向 $\to$ 非负向分别为 GPT $12.62\%\to17.31\%$、Gemini $3.62\%\to6.05\%$、Qwen $12.58\%\to27.01\%$、Gemma $8.68\%\to16.69\%$。

但式 1 的 SIR 可以化简。三个类别概率之和为 $1$，所以 $\Pr(\text{Speaker})+\Pr(\text{Reference})=1-\Pr(\text{Undecided})$，代回去得到

$$
\mathrm{SIR}=\Pr(\text{Speaker}).
$$

也就是说 SIR 就是「答案指向说话人」的比例，式 1 的归一化项被自己抵消了。

论文没有报告 $\Pr(\text{Undecided})$。BBQ 的歧义语境里正确答案是「无法判断」，而默认 prompt 要求「Give a concise one-sentence answer. Do not ask for clarification」，这会把模型往「必须选一边」推。Gemini 的 SIR 最低，可能只是它更常答「无法判断」，Table 3 里它 $32.62\%$ 的 Helpful 率（四者最低）与这个解释一致。这一点只是推测，论文没有给出能区分两种解释的数字。

### 有没有躲开的基线

数据集型论文的「基线」有两层：同任务的已有评测集，以及能把「真人语音」这一卖点单独剥离出来的对照实验。两层都缺。

检索记录：OpenAlex 返回 `Rate limit exceeded`（当日免费额度为 $0$），未拿到结果；Semantic Scholar 返回 `Too Many Requests`；DBLP 返回空响应；free-search 的 bing 通道对三组英文查询都返回了 4399、百度百科、知乎等无关页面，检索失败。最终靠 arxiv.org 站内检索页（`arxiv.org/search`，两组查询）和逐篇抓摘要页拿到下面的工作，GitHub 检索可用。仓库内既有评审里没有命中 VoiceBBQ、voice bias、Spoken BBQ 等关键词的 `.md` 评审。

1. **VoiceBBQ（arXiv 2509.21108，EMNLP 2025 main）。** 论文引用为 [3]，没有任何数值对比。VoiceBBQ 正是 BBQ 的 TTS 语音版，与 HEAR 的 Spoken BBQ 同源。论文的核心论点是「TTS 合成语音限制了生态效度」，而验证这一点最直接的实验，是在同一批 BBQ 题目上比较 TTS 版与真人版的指标差异。论文没有做，于是「real voice」这一卖点在实验里没有得到任何支撑。
2. **VIBE（arXiv 2604.17248，2026 年 4 月提交，投 SLT 2026）。** 论文没有引用。VIBE 摘要原话是「evaluates generative bias through open-ended tasks such as personalized recommendations, using human-recorded speech」，评测了 $12$ 个 LALM，用的是 CREMA-D、L2-ARCTIC、Speech Accent Archive 等真人录音库。它与 HEAR 的 Open QA 在问题形式和动机上高度重合，并且比 HEAR 早五个月。HEAR 的「first large-scale voice benchmark grounded entirely in authentic human speech」在「专门招募、知情同意、规模 $843$ 人」这个限定下还站得住，去掉限定就站不住。
3. **FairDialogue（arXiv 2510.02352，2025 年 9 月）。** 论文没有引用。它评测了 GPT-4o Audio、Gemini-2.5-Flash 等端到端语音对话模型在决策和推荐任务上的年龄、性别偏见，并放出了数据与代码，与 HEAR 的 S2S 评测部分同题。
4. **BiasInEar（arXiv 2602.01030，EACL 2026 Findings）。** 论文没有引用。它在 $9$ 个模型上得出「MLLMs are relatively robust to demographic factors」，与 HEAR 的「性别 VCD 达 $12$–$26\%$」方向相左。两者结论冲突，HEAR 至少应讨论差异来自真人语音、指标定义还是模型选择。
5. **The Voice Behind the Words（arXiv 2603.16941，Interspeech 2026）。** 论文没有引用。它用 voice cloning 固定内容、比较口音×性别交叉偏见，并做了人工验证。
6. **Semantic-aware mixed-effects 公平性评估（arXiv 2608.13624，2026 年 8 月）。** 论文没有引用。它把 speaker identity 当随机效应建模，专门处理「同一说话人贡献多条样本」带来的伪显著。HEAR 每个说话人平均贡献约 $47$ 条 BBQ 录音（$39{,}334/839$，按 README 数字算），正好需要这一类处理。
7. **最小对照：纯文本转写输入。** 把同一句话的文字转写直接喂给同一模型，可以把「内容偏见」与「声音偏见」分开，也可以排除「声音只是导致识别出错、进而答案翻转」这一解释。论文的 VCD 衡量的是正/负向问题之间答案类别的翻转率，非英语母语者的口音如果导致更多理解错误，同样会推高 VCD(Non-EN,EN)。论文没有文本对照，也没有报告任何识别或理解准确率。

模型侧只有 $4$ 个，GPT Realtime 和 Gemini Realtime 都没给版本号或日期快照。VIBE 评测了 $12$ 个，FairDialogue 覆盖了 GLM-4-Voice、Qwen2.5-Omni 等开源 S2S 模型，HEAR 的 S2S 一侧只有两个闭源 API。

### 增益是否超出评测误差

论文全篇没有方差、置信区间或 seed 数。Table 1 标题写了「The distribution of metrics are statistically different based on Mann-Whitney U test」，但没写比较的是哪两个分布、$p$ 值多少、做了多少次检验。生成温度、每题采样次数、S2S 模型的语音输出如何归入 A/B/C 三类，都没有说明。

下面的噪声量级全部是我的估算。

**Open QA 的 Disparity 大多落在零假设的噪声内。** Table 3 里所有 Disparity 都是 $2\%$ 的整数倍，与 $50$ 个问题对得上。DDR 定义为「卡方检验显著的问题占比」，论文没写显著性水平，也没写是否做多重比较校正。

假设 $\alpha=0.05$、每题一次检验、各题独立，那么一个完全无偏的模型也会有约 $2.5$ 题「显著」。按二项分布 $\mathrm{Bin}(50,0.05)$ 算尾概率：

- $\ge 3$ 题（$6\%$）的概率约 $0.46$；
- $\ge 4$ 题（$8\%$）约 $0.24$；
- $\ge 5$ 题（$10\%$）约 $0.10$；
- $\ge 9$ 题（$18\%$）约 $0.0008$。

据此，GPT 的 $8\%/6\%$、Gemini personalized 的 $6\%$、Gemma 的 $10\%/8\%$ 都与「完全无偏」无法区分。能确定超出噪声的只有 Gemini 默认 $18\%$、Qwen 默认 $22\%$ 和 Qwen personalized $54\%$。

如果每题对性别、年龄、族裔、家庭语言分别检验再取并集，零假设下的假阳性率还会更高。论文 §3.2.3 的定义没说清是哪一种。

因此，§5 里「personalized 降低多数模型 disparity」以及 GPT 与 Gemma 之间的排序，在这个样本量下都没有统计意义。

**Spoken BBQ 的性别差距大于抽样噪声，但混杂没有排除。** 按 README，BBQ 部分 $39{,}334$ 条录音、$194$ 个题目，平均每题约 $203$ 条；参与者女性 $507$、男性 $325$。若只算抽样噪声，单题上两组翻转率之差的标准误在 $6$–$7$ 个百分点，平均到 $194$ 题后降到 $1$ 个百分点以内。$12$–$26\%$ 的性别 VCD 远大于这个量级。

不过这个估算假设各题独立。同一批说话人在不同题目上重复出现，有效样本量更接近说话人数而非录音数，误差会被低估。

性别组之间的其他属性也不平衡，论文没有分层或回归控制。手机在家录音的信道条件因人而异，同样没有控制。

**年龄轴的噪声可能大到不可用。** 论文没定义「Old」和「Young」各包括哪些年龄段。参与者里 $66+$ 只有 $23$ 人，按每人约 $47$ 条估算，每题只有 $5$–$6$ 条老年录音。如果「Old」指 $66+$，VCD(Old,Young) 的有效样本只有 $23$ 个说话人，Table 1 里这一列在 $-20.62\%$ 到 $+18.21\%$ 之间来回变号，与高方差的表现一致。

**循环评测与指标选择。** Open QA 的回答如何归类成卡方检验所需的离散类别、Helpful 率如何判定，论文都没写。如果用了 LLM 归类，评测结果会混入归类模型自身的偏见。personalized prompt 原文是「Analyze the demographic features of the speaker」，等于直接要求模型按人口属性区别对待，再测出差异增大，这一设计更接近验证指令遵循，而非测量自然部署下的偏见。

## 公理审查结果

### 公理一：对象公理
- 判定: ⚠️
- 分数: 6
- 依据: 语音输入让模型能「听见」说话人的性别、年龄、口音，这一偏见来源真实，用真人录音补上 TTS 评测的生态效度缺口也是合理的问题定义。但范围有夸大：摘要称「voice bias is a controllable model characteristic」，全文只有两条 system prompt 的对比，并且 Table 3 上 $3/4$ 模型的方向与「放大」相反；局限性一节承认仅限英语、仅限美国居民。
- Wiki 证据: arxiv.org 站内检索确认同期已有 VIBE（2604.17248，真人录音、开放式任务）、FairDialogue（2510.02352）等同题工作；OpenAlex、Semantic Scholar 限流，DBLP 空响应，free-search 返回无关页面。

### 公理二：识别公理
- 判定: ❌
- 分数: 3
- 依据: 论文的核心卖点是「真人语音优于 TTS」，却没有在同一批 BBQ 题上与 VoiceBBQ（EMNLP 2025）的 TTS 版做任何对照；没有纯文本转写输入的最小对照来分离内容偏见、声音偏见与识别错误；VIBE、FairDialogue、BiasInEar、Voice Behind the Words 四篇 2025–2026 同题工作均未引用，其中 VIBE 早五个月就用真人录音做了开放式偏见评测，BiasInEar 的结论与本文相左。被评测模型只有 $4$ 个，S2S 一侧没有开源模型，闭源模型无版本号。
- Wiki 证据: VoiceBBQ、VIBE、FairDialogue、BiasInEar、Voice Behind the Words、2608.13624 的摘要均从 arxiv.org abs 页面抓取核对；VIBE 正文确认其用 CREMA-D、L2-ARCTIC、Speech Accent Archive 并评测 $12$ 个 LALM。仓库内既有评审中无同题锚点。

### 公理三：独立性公理
- 判定: ⚠️
- 分数: 4
- 依据: 评测数据与被测模型的训练无关，这一点没问题。但 S2S 模型语音输出如何归入 A/B/C、Open QA 回答如何离散化、Helpful 率如何判定，论文都没写，无法排除 LLM 归类器引入的二次偏见。personalized prompt 明确要求「Analyze the demographic features of the speaker」，再测「人口差异增大」，带有循环性质。Table 1 所称 Mann-Whitney U 检验没有给出比较对象和 $p$ 值。
- Wiki 证据: 论文 GitHub 仓库只有 `download.py`、三份 metadata CSV 和 `release_assets.json`，没有评测或归类代码，归类方式无从核对。

### 公理四：压缩公理
- 判定: ⚠️
- 分数: 5
- 依据: 五个指标里 SIR 按式 1 可化简为 $\Pr(\text{Speaker})$，归一化项被抵消；FR 的式 2 括号错位，且「$N$ is the set of different prompt clusters」把集合与计数混用，Table 2 还对非负向问题报了 FR，而定义只针对负向问题；Table 1 表头列出 $11$ 列，每行只有 $5$ 个数。DDR 用「显著题目占比」度量偏见，没有处理多重比较，在 $50$ 题上分辨率只有 $2\%$。指标数量多，可解释性和统计性质都没交代清楚。
- Wiki 证据: 无需检索，依据为论文式 1–4 与 Table 1–3 的直接核对。

### 公理五：效用公理
- 判定: ⚠️
- 分数: 5
- 依据: 数据本身有实际效用：$87{,}653$ 条 16 kHz 无损录音、$843$ 名带自报人口属性的说话人（女 $507$ / 男 $325$ / 非二元 $11$；族裔中 White $228$、Hispanic $190$、Black $162$），知情同意明确覆盖公开发布，这在同题工作里少见。但论文从数据里得出的结论多处与自身表格矛盾（「所有模型」「consistently」「一致放大」三处均被 Table 1/3 反驳），Open QA 里 $7$ 个 Disparity 格子有 $5$ 个按我的二项估算与零假设无法区分。数据值得用，论文的分析结论不宜直接引用。
- Wiki 证据: `metadata/participants.csv` 从 GitHub 拉取后统计得到上述人口分布；README 给出 bbq $39{,}334$ 条 / openqa $48{,}319$ 条。

### 公理六：新颖性公理
- 判定: ⚠️
- 分数: 5
- 依据: 在检索到的同题工作里，HEAR 是唯一一个为偏见评测专门招募、按同一脚本录制、知情同意覆盖公开发布的真人录音集，这是真实的新增量。VIBE 复用的 Speech Accent Archive 说话人数并不少，但那是朗读同一段固定文本的口音库，无法承载 BBQ 式的题目。而 Spoken BBQ 的构造沿用 VoiceBBQ 的思路（BBQ 改语音），Open QA 的「按人口组比较回答分布」与 VIBE、FairDialogue 同构，指标层面 SIR 退化为单一概率。「first large-scale voice benchmark grounded entirely in authentic human speech」需要加上「专门录制」的限定才成立。
- Wiki 证据: VIBE（2604.17248）摘要明确写「using human-recorded speech」，早于本文；GitHub 搜「VoiceBBQ」命中第三方复现仓库 `seoljh301/SLM-Bias`，说明该方向已有人跟进。

### 公理七：可复现公理
- 判定: ⚠️
- 分数: 6
- 依据: 数据已公开：`facebookresearch/hear_voice_bias_benchmark` 的 v1.0 Release 于 2026-09-29 发布，$113$ 个资产、$12.91$ GiB，带 SHA256 校验和下载脚本，许可为 CC BY-NC 4.0。但没有评测代码、没有归类 prompt 或规则、没有模型版本与解码参数，Table 1–3 的数字无法从公开材料复算。
- Wiki 证据: `gh repo view` 显示仓库 $2$ star、创建于 2026-09-13；`gh release view` 确认 Release 资产数；仓库文件列表中无评测脚本。

## 总评

HEAR 的价值集中在数据上。真人录音、知情同意明确、$843$ 人、人口属性自报，这些条件在同题工作里很难凑齐，并且已经按可校验的方式放了出来。对做语音偏见研究的人来说，这份数据可以直接拿来替换 TTS 版的 BBQ。

主要问题在于论文从这份数据里得出的结论站不住。

第一，三条主结论被自己的表格反驳：年龄方向在 Table 1 的 $8$ 个格子里 $4$ 个变号，Gemini 在语言轴上 VCD 最高，personalization 在 Table 3 上让 $3/4$ 模型的 disparity 下降，摘要却写成「consistently exacerbate」。

第二，「真人语音比 TTS 更能暴露偏见」这一立论前提，没有任何 TTS 对照实验支撑，VoiceBBQ 就在引用列表里。
